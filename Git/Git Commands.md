- git init - команда для создания локального гит репозитория в папке
- git status  - все файлы которые отслеживает гит
- git add имя_файла.расширение - гит добавляет файл в пул отслеживаемых
- git commit -m " - " - коммит с подписью в кавычках 
- git log --oneline - вывод всех коммитов
- git commit --amend -m " - " - изменение имени коммита (Полностью отменяет старый коммит и создаёт новый)
- git add -A - отслеживаем все не отслеживаемые файлы в проекте
- git checkout хеш - переключение на коммит с данным хешем
- git checkout main - вернулись в последний созданный коммит
- git log --oneline --all - все коммиты которые есть
- ssh-keygen - создание SSH ключа (генерация)
- cat ~/.ssh/id_ed25519.pub - получение ssh ключа
- git remote -v -проверка на связь папки с удалённым репозиторием
- git remote add origin ссылка на ssh ключ - подключение к удалённому репозиторию
- git push -u origin ветка в которой работаем - отправка файлов с локального на удалённый репозиторий гит
- git clone Ссылка на SSH из Git - Команда для копирования репозитория, создаётся новая папка с названием удалённого репозитория
- cd путь к папке - открытие нужной папки внутри gitbash
- git branch - просмотр веток которые уже есть в репозитории
- git branch имя ветки - создание новой ветки
- git checkout имя ветки - просмотр ветки которая нужна
- git log имя ветки --oneline - просмотр всех коммитов в ветке (история)
- git merge имя ветки - слияние веток, находим в ветке в которую хотим слить, в команду пишем имя ветки из которой берём изменения
- git commit -a -m "имя коммита" - одновременно и отслеживать и закоммитить файлы (сокращённая команда от 2 команд git add и git commit -m " - ")
- git pull - обновление нашей папки с удалённого репозитория (при большом количестве сообщений esc, :wq, enter или ctrl +x, Y, enter )
- git revert хэш - отменяет последний коммит и создаёт зеркальный коммит, то есть коммитов будет не на 1 меньше а на 1 больше 
-  git rm --cached имя файла - удаляем  файл из индекса, из отслеживаемых, но оставляем его на компьютере
