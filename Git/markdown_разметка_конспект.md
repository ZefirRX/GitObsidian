# Конспект по Markdown
## Что такое Markdown
Markdown — лёгкий язык разметки для форматирования текста.
## Заголовки
```
# Заголовок 1
## Заголовок 2
### Заголовок 3
```
## Текст
```
*курсив* или _курсив_  
**жирный**  
~~зачёркнутый~~
```
## Списки
```
- Пункт 1
- Пункт 2
  - Подпункт
```

```
1. Первый
2. Второй
```
## Ссылки
```
[Текст ссылки](https://example.com)
```
## Изображения
```
![Описание](https://example.com/image.png)
```
## Код
`код`
```python
print("Hello, world!")
```
## Таблицы
```

| Имя  | Возраст | 
| ---- | ------- |
| Анна | 25      |
| Иван | 30      |

```
## Цитаты
```
> Это цитата
```
## Чек-листы
```
- [x] Сделано
- [ ] Не сделано
```
## Разделитель
```
---
```
## Выделенная цитата
```
>[!notes]
```
