1. Имя файла должно начинаться с точки, а в конце не должно быть никакого расширения
2. Правила игнорирования срабатывают только для файлов, не добавленных в индекс, не отслеживаемых до команды git add.
Для игнора целой папки прописываем в файл gitignore название файла и слеш на конце
``` gitignore
private/
```
Для игнорирования только файл с определённым именем записываем его с расширением, пример ниже
```gitignore
README.md
```
Для игнорирования всех файлов с определённым расширением пропишем * а пото расширение с точкой в начале, пример ниже
```gitignore
*.md 
```
 Для игнора файла в определённой папке пропишем путь к этому файл. В примере ниже будет проигнорирован файл todo.md
```gitignore
private/todo.md
```
