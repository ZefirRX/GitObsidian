# Шаблоны и функторы

> [!abstract] О чём заметка
> **Шаблоны (templates)** позволяют написать функцию или класс один раз и использовать с любыми подходящими типами, не дублируя код. **Функторы (functors)** — объекты, которые можно вызывать как функции и которые при этом хранят состояние. Вместе они лежат в основе STL: контейнеры — это шаблоны классов, а поведение алгоритмов настраивается функторами (см. [[06 STL часть 1]] и [[07 STL часть 2]]).

## Зачем нужны шаблоны

Допустим, нужна функция, возвращающая большее из двух чисел. Для `int`, `double` и `char` придётся написать три почти одинаковых функции — отличаются только типы:

```cpp
int    max(int a, int b)       { if (a > b) return a; else return b; }
double max(double a, double b) { if (a > b) return a; else return b; }
char   max(char a, char b)     { if (a > b) return a; else return b; }
```

А если потом понадобится `std::string`? Каждый раз копировать код — это **дублирование**, а значит, лишние места для ошибок. Решение — шаблон: тип становится параметром.

## Шаблоны функций

Чтобы сделать шаблон, нужно:

1. Перед объявлением функции написать `template <class T>` (или `template <typename T>` — это то же самое);
2. В теле и сигнатуре заменить конкретный тип на `T`.

```cpp
#include <iostream>

template <class T>
T my_max(T a, T b)
{
    if (a > b)
        return a;
    else
        return b;
}

int main()
{
    std::cout << my_max(3, 7) << "\n";       // Вывод: 7   (T = int)
    std::cout << my_max(2.5, 1.5) << "\n";   // Вывод: 2.5 (T = double)
}
```

**Шаблон — это не функция, а рецепт для её создания.** Пока шаблон не вызван, компилятор не порождает для него никакого кода в бинарном файле. При вызове компилятор сам подставляет нужные типы и создаёт (**инстанцирует**, instantiate) обычную функцию для этих типов. После этого вызов шаблонной функции ничем не отличается от вызова обычной.

> [!warning] Где определять шаблон
> Компилятор должен видеть **полное определение** шаблона в той единице трансляции, где он используется. Поэтому шаблоны пишут целиком в заголовочных файлах: если вынести реализацию в отдельный `.cpp`, получите ошибку линковки (см. [[01 Компиляция и линковка]] и [[08 Многофайловые проекты и библиотеки]]).

### Вывод типа и явное указание

Компилятор выводит `T` по аргументам. Если они разных типов, вывод не удаётся:

```cpp
my_max(0, 5.0);   // ошибка: deduced conflicting types for parameter 'T' ('int' and 'double')
```

`T` не может быть одновременно `int` и `double`. Выход — указать тип явно в угловых скобках, тогда аргументы просто преобразуются к нему:

```cpp
std::cout << my_max<double>(0, 5.5) << "\n";   // Вывод: 5.5
```

### Требования к типу

Шаблон работает только с теми типами, для которых компилируются все операции в его теле. В `my_max` это оператор `>`:

```cpp
class dog {
    unsigned m_age;
public:
    dog(unsigned age) : m_age{age} {}
};

my_max(dog(1), dog(5));   // ошибка: у dog нет оператора >
```

Чтобы такой вызов заработал, нужно перегрузить `operator>` для `dog` (см. [[04 Перегрузка операторов]]). Ошибка при этом возникает не в шаблоне как таковом, а в момент подстановки конкретного типа.

### Специализация шаблона функции

Иногда общий алгоритм для какого-то типа даёт не то, что нужно. Например, `std::string` сравнивается лексикографически, а мы хотим выбирать более **длинную** строку. Для этого пишут **полную специализацию (full specialization)**: после основного шаблона задают отдельную реализацию для конкретного типа, начав с `template <>`.

```cpp
#include <iostream>
#include <string>

template <class T>
T my_max(T a, T b) { return (a > b) ? a : b; }

template <>                                   // полная специализация: T заменён на std::string
std::string my_max(std::string a, std::string b)
{
    return a.length() > b.length() ? a : b;
}

int main()
{
    std::cout << my_max<std::string>("apple", "fig") << "\n";            // Вывод: apple (длиннее)
    std::cout << my_max(std::string("zz"), std::string("abc")) << "\n";  // Вывод: abc
    std::cout << my_max(3, 7) << "\n";                                   // Вывод: 7 (общий шаблон)
}
```

Для всех остальных типов используется общий шаблон, для `std::string` — специализация. «Полной» она называется потому, что параметр `T` заменён явным типом целиком.

> [!tip] Обратите внимание
> Вызов `my_max("apple", "fig")` с литералами вывел бы `T = const char*` и сравнивал бы **адреса**, а не строки. Поэтому в примере используются `std::string` явно.

## Шаблоны классов

Шаблонами можно описывать и классы — именно так устроены `std::vector<int>`, `std::map<K, V>` и другие контейнеры. Синтаксис такой же: `template <class T>` перед классом. При создании объекта `simple_array<int>` компилятор порождает класс с `T = int`; `simple_array<char>` — это уже другой, отдельный класс.

```cpp
#include <iostream>
#include <string>

template <class T>
class simple_array
{
public:
    explicit simple_array(int n) : elements(new T[n]()), num(n) {}
    simple_array(const simple_array&) = delete;             // иначе двойное delete[] при копировании
    simple_array& operator=(const simple_array&) = delete;
    T getElement(int i) const { return elements[i]; }
    void setElement(int i, const T& v) { elements[i] = v; }
    ~simple_array() { delete[] elements; }
private:
    T* elements = nullptr;
    int num = 0;
};

int main()
{
    simple_array<int> a(4);
    a.setElement(1, 42);
    std::cout << a.getElement(1) << " " << a.getElement(0) << "\n";   // Вывод: 42 0

    simple_array<std::string> s(2);
    s.setElement(0, "hi");
    std::cout << s.getElement(0) << "|" << s.getElement(1) << "|\n";  // Вывод: hi||
}
```

> [!warning] Исправление относительно слайдов
> В слайдах конструктор и `setElement` использовали несуществующее имя `Type` вместо `T`, а копирование не было запрещено. Класс владеет памятью (`new[]`), поэтому копирование по умолчанию привело бы к двойному освобождению — см. [[02 Жизненный цикл объекта и RAII]] (правило трёх/пяти).

### Несколько параметров

Параметров может быть сколько угодно, и это могут быть не только типы, но и значения (как `int I` ниже, или размер `std::array<int, 3>`):

```cpp
template <class T, class U>
struct Pair { T first; U second; };

Pair<char, std::string> p{'x', "str"};   // p.first == 'x', p.second == "str"
```

### Полная специализация класса

Для конкретных типов можно подменить весь класс целиком:

```cpp
#include <iostream>

template <class T>
struct Test { Test() { std::cout << "Class template\n"; } };

template <>
struct Test<float> { Test() { std::cout << "Float template specialization\n"; } };

int main()
{
    Test<int> a;     // Вывод: Class template
    Test<char> b;    // Вывод: Class template
    Test<float> c;   // Вывод: Float template specialization
}
```

### Частичная специализация класса

**Частичная специализация (partial specialization)** обобщает полную: фиксируется только часть параметров или их «форма», остальные остаются шаблонными. Она есть **только у классов** (у функций вместо неё используют перегрузку).

```cpp
template <class T1, class T2, int I> class A {};              // основной шаблон
template <class T, int I>            class A<T, T*, I> {};    // #1: T2 — указатель на T1
template <class T, class T2, int I>  class A<T*, T2, I> {};   // #2: T1 — указатель
template <class T>                   class A<int, T*, 5> {};  // #3: T1 = int, T2 — указатель, I = 5
```

Самый частый случай — специализация «для любых указателей»:

```cpp
#include <iostream>

template <class T> struct Kind    { static const char* name() { return "обычный тип"; } };
template <class T> struct Kind<T*> { static const char* name() { return "указатель"; } };

int main()
{
    std::cout << Kind<int>::name() << ", " << Kind<int*>::name() << "\n";
    // Вывод: обычный тип, указатель
}
```

Компилятор выбирает **наиболее специализированный** из подходящих вариантов.

## Функторы

**Функтор (functor, функциональный объект)** — это класс, в котором определён оператор вызова `operator()`. Объект такого класса можно вызывать как функцию — `obj(args)`, но, в отличие от функции, он может **хранить состояние** в полях: счётчик вызовов, параметры, накопленный результат. Это удобнее глобальных переменных.

```cpp
#include <iostream>
#include <string>

class simple_functor {
    std::string m_name;
    int m_counter = 0;                       // сколько раз вызывали
public:
    explicit simple_functor(std::string name) : m_name(std::move(name)) {}
    void operator()() {                      // оператор круглых скобок
        std::cout << "Hello, " << m_name << "\n";
        ++m_counter;
    }
    int calls() const { return m_counter; }
};

int main()
{
    simple_functor sf("Alex");
    sf();                                    // Вывод: Hello, Alex
    sf();                                    // Вывод: Hello, Alex
    std::cout << sf.calls() << "\n";         // Вывод: 2
}
```

`operator()` может принимать аргументы и возвращать значение, как любая функция:

```cpp
class adder {
    int m_counter = 0;
public:
    int operator()(int a, int b) { ++m_counter; return a + b; }
};
// adder sf; auto r = sf(1, 4);   // r == 5
```

### Функтор и лямбда-функция

**Лямбда-выражение — это тот же функтор**, только анонимный: компилятор сам создаёт безымянный класс, тело лямбды становится телом его `operator()`, а захваченные переменные (`[k]`) — полями. Лямбда — «синтаксический сахар», делающий код короче. Явный класс-функтор удобен, когда логика большая, нужна в нескольких местах или требует нескольких методов.

Преимущества функтора перед обычной функцией:

1. его можно **параметризовать** при создании через конструктор;
2. на время вызова создаётся временный объект;
3. он может хранить любое количество дополнительной информации.

## Использование в STL

### Предикаты

**Предикат (predicate)** — функция или функтор, возвращающий (обычно) `bool` и используемый для настройки алгоритма. Классический пример — порядок сортировки:

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

struct Greater {
    bool operator()(int a, int b) const { return a > b; }   // слайды возвращали int; bool точнее
};

int main()
{
    std::vector<int> vec{1, 10, 7, -9, 4};
    std::sort(vec.begin(), vec.end(), Greater());
    for (int x : vec) std::cout << x << " ";   // Вывод: 10 7 4 1 -9  (по убыванию)
}
```

В стандартной библиотеке уже есть готовые функторы в `<functional>`: `std::less<T>`, `std::greater<T>`, `std::plus<T>` и др. — то есть `Greater()` можно заменить на `std::greater<int>()`.

### Настройка действия алгоритма

Функтор с состоянием передаёт алгоритму параметр. Алгоритм `std::transform` применяет функтор к каждому элементу:

```cpp
class AddValue {
    int v;                                          // что прибавлять
public:
    explicit AddValue(int v) : v(v) {}
    int operator()(int x) const { return x + v; }
};

std::vector<int> vec{1, 10, 7, -9, 4};
std::transform(vec.begin(), vec.end(), vec.begin(), AddValue(4));
// vec: 5 14 11 -5 9

int k = 3;
std::transform(vec.begin(), vec.end(), vec.begin(), [k](int x) { return x * k; });  // то же лямбдой
// vec: 15 42 33 -15 27
```

## Задачи для практики

- Напишите шаблон `my_min` и специализацию для `const char*`, сравнивающую строки через `strcmp`. *Решение:* `template <> const char* my_min(const char* a, const char* b) { return std::strcmp(a, b) < 0 ? a : b; }`.
- Реализуйте функтор-счётчик «сколько элементов больше порога» и передайте его в `std::for_each` или `std::count_if`. *Решение:* порог хранится полем; `count_if` принимает функтор как предикат.
- Напишите шаблон класса `Stack<T>` на основе `std::vector<T>` с методами `push`, `pop`, `top`.

## Частые ошибки

- Разные типы аргументов при выводе `T`: `my_max(1, 2.5)` — не компилируется; указывайте `my_max<double>` явно.
- Реализация шаблона в `.cpp` вместо заголовка — ошибка линковки.
- Шаблон вызван для типа без нужного оператора (`>`, `<`, `==`) — ошибка длинная и запутанная, но смысл один: типу не хватает операции.
- Передача строковых литералов в шаблон сравнения: сравниваются указатели.

## Кратко (шпаргалка)

| Понятие | Запись / смысл |
|---|---|
| Шаблон функции | `template <class T> T f(T x)`; код создаётся при использовании |
| Явный тип | `f<double>(1, 2.5)` |
| Полная специализация | `template <> ...` для конкретных типов |
| Частичная специализация | `template <class T> class A<T*>`; только для классов |
| Функтор | класс с `operator()`, умеет хранить состояние |
| Лямбда | анонимный функтор |
| Предикат | функтор/функция, возвращающая `bool`, для настройки алгоритма |
