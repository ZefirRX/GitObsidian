# STL, часть 2 — итераторы и алгоритмы

> [!abstract] О чём заметка
> **Итератор (iterator)** — объект, который умеет перебирать элементы контейнера, не раскрывая его внутреннего устройства. Итераторы позволяют алгоритмам STL (`find`, `sort`, `remove_if`, `unique`...) работать с любым контейнером одинаково. Заметка продолжает [[06 STL часть 1]].

## Зачем нужны итераторы

При проектировании STL решили **разделить контейнеры и алгоритмы**: алгоритм `find` написан один раз и работает и с вектором, и со списком, и с множеством. Но как алгоритму добраться до данных, не зная устройства контейнера? Для этого введена промежуточная сущность — итератор. Каждый контейнер определяет свой класс итератора, который знает, как переходить к следующему элементу именно в этом контейнере.

Итераторы можно считать «безопасными указателями» с расширенным функционалом. Для сравнения, обход обычного массива арифметикой указателей (см. [[07 Указатели и массивы]]):

```cpp
int arr[] = {1, 7, 14, -5};
auto a = arr[2];          // 14
auto b = *(arr + 2);      // то же: сдвиг указателя на 2 элемента
```

Это работает лишь потому, что элементы массива лежат в памяти подряд. У `list`, `set`, `map` элементы разбросаны, сдвиг «на два адреса» привёл бы к неопределённому поведению, а `operator[]` у многих контейнеров вообще не определён. Итератор прячет эти различия.

## Категории итераторов

Не все контейнеры умеют одно и то же, поэтому итераторы делятся на категории — каждая следующая умеет всё, что предыдущая, и больше:

```text
Input ──> Forward ──> Bidirectional ──> Random access
(Output — отдельная категория: итератор, в который можно писать)
```

| Категория | Возможности | Кто такой итератор имеет |
|---|---|---|
| Input | чтение, однопроходный инкремент | потоки ввода (`istream_iterator`) |
| Output | запись | потоки вывода, `back_inserter` |
| Forward | + инкремент с несколькими проходами | `forward_list`, `unordered_*` |
| Bidirectional | + декремент (`--`) | `list`, `set`, `map` |
| Random access | + произвольный доступ (`it + n`, `it[n]`, сравнения `<`, `>`) | `vector`, `array`, `deque` |

От категории зависит, какие алгоритмы применимы: например, `std::sort` требует random access, поэтому для `std::list` у него свой метод `sort`.

## Операции над итераторами

- **разыменование** `*it` — получить элемент, на который указывает итератор;
- **инкремент** `++it` — перейти к следующему элементу;
- **декремент** `--it` — перейти к предыдущему (с bidirectional);
- **равенство** `it1 == it2` — равны, если указывают на один элемент;
- **неравенство** `it1 != it2`;
- **сравнения** `<`, `>` (random access): итератор «больше», если указывает ближе к концу.

Каждый контейнер имеет два основных типа итераторов — `container::iterator` и `container::const_iterator` (только чтение) — и четыре функции их получения:

| Функция | Что возвращает |
|---|---|
| `begin()` | итератор на первый элемент |
| `end()` | итератор на позицию **за последним** элементом (на сам элемент разыменовывать нельзя) |
| `cbegin()` / `cend()` | то же, но константные |
| `rbegin()` / `rend()` | обратные итераторы (обход с конца) |

Полуинтервал `[begin, end)` удобен для циклов: пустой контейнер — это `begin == end`, а условие остановки `it != end` одинаково для всех контейнеров.

## Обход контейнера

```cpp
#include <iostream>
#include <vector>

int main()
{
    std::vector<int> v = {0, 1, 2, 3, 4, 5};

    // Изменение элементов через итератор
    for (auto i = v.begin(); i != v.end(); ++i)
        *i = *i * 2;                                   // v: 0 2 4 6 8 10

    // Только чтение — константные итераторы
    for (auto i = v.cbegin(); i != v.cend(); ++i)
        std::cout << *i << " ";                        // Вывод: 0 2 4 6 8 10
    std::cout << "\n";

    // Обратный обход: ++ на reverse_iterator движется к началу
    for (auto r = v.rbegin(); r != v.rend(); ++r)
        std::cout << *r << " ";                        // Вывод: 10 8 6 4 2 0
    std::cout << "\n";
}
```

> [!tip] Предпочитайте `auto` и `++it`
> Тип `std::vector<int>::iterator` громоздок — используйте `auto`. Префиксный `++it` не создаёт лишней копии итератора. Если элементы не меняются — берите `cbegin/cend` или `const auto&` в range-for.

Через `const_iterator` присваивание `*i = ...` не скомпилируется — компилятор защитит от случайного изменения.

### Итераторы разных контейнеров

У `vector` итератор random access — можно прибавлять число; у `set` — только bidirectional, поэтому `it + 2` не скомпилируется, нужны `std::advance`, `std::next`, `std::prev`, `std::distance` (они работают для любых итераторов; для random access — за $O(1)$, для остальных — шагами):

```cpp
#include <algorithm>
#include <iostream>
#include <iterator>
#include <set>
#include <vector>

int main()
{
    std::vector<int> v = {0, 1, 2, 3, 4, 5};
    auto it = v.begin();
    auto it2 = it + 2;                                  // random access: можно
    std::cout << *it2 << " ";                           // Вывод: 2
    std::cout << (it2 == std::find(v.begin(), v.end(), 2)) << " ";  // Вывод: 1 (true)
    ++it2;
    std::cout << (it2 == std::find(v.begin(), v.end(), 2)) << "\n"; // Вывод: 0 (false)

    std::set<int> s = {0, 1, 2, 3, 4, 5};
    auto si = s.begin();
    // auto bad = si + 2;                               // ошибка компиляции
    std::advance(si, 2);                                // сдвиг на 2 элемента
    std::cout << *si << " " << *std::next(si) << " " << *std::prev(si) << " "
              << std::distance(s.begin(), si) << "\n";  // Вывод: 2 3 1 2
}
```

Слайды содержали опечатку `finded` вместо `found` — здесь исправлена.

## Итераторы в методах контейнеров

Вставка и удаление в контейнерах принимают итераторы как позиции:

```cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>

int main()
{
    std::vector<std::string> animals = {"dog", "lama", "cat", "tortoise"};

    auto it = std::find(animals.begin(), animals.end(), "lama");  // позиция lama
    animals.erase(it);                      // dog cat tortoise
    animals.insert(animals.begin(), "bear");// bear dog cat tortoise
    auto it1 = std::find(animals.begin(), animals.end(), "cat");
    animals.erase(it1, animals.end());      // удалили от cat до конца: bear dog
    for (auto& a : animals) std::cout << a << " ";   // Вывод: bear dog
    std::cout << "\n";

    animals = {"dog", "lama", "cat", "tortoise"};
    animals.insert(animals.begin(), 2, "bear");            // две копии
    animals.insert(animals.begin(), {"horse", "fox"});     // список значений
    for (auto& a : animals) std::cout << a << " ";
    // Вывод: horse fox bear bear dog lama cat tortoise
}
```

`insert` перед указанной позицией; `erase(first, last)` удаляет полуинтервал `[first, last)`.

> [!warning] Инвалидация итераторов
> После вставки или удаления итераторы на изменённый контейнер могут стать недействительными (у `vector` — все итераторы после точки изменения, а при перевыделении памяти — вообще все). Поэтому в цикле с удалением используют результат `erase`, который возвращает итератор на следующий элемент:
> ```cpp
> for (auto i = e.begin(); i != e.end(); ) {
>     if (*i % 2 == 0) i = e.erase(i);   // erase вернул следующий
>     else ++i;
> }
> ```
> Для `e = {1,2,3,4,5,6}` останется `1 3 5`.

## Алгоритмы и идиома erase-remove

Алгоритмы из `<algorithm>` получают диапазон `[first, last)` и не знают о контейнере. Поэтому они **не могут изменить размер** контейнера — только переставить или перезаписать элементы.

### std::remove_if

Задача: удалить животных, у которых вторая буква — `'o'`.

```cpp
std::vector<std::string> animals = {"dog", "lama", "cat", "tortoise"};
auto new_end = std::remove_if(animals.begin(), animals.end(),
    [](const std::string& a) { return a[1] == 'o'; });
animals.erase(new_end, animals.end());
// animals: lama cat
```

**Что делает `remove_if`:** сдвигает «нужные» элементы в начало диапазона, перезаписывая удаляемые, и возвращает итератор на **новый логический конец**. Хвост за ним содержит неопределённое (moved-from) содержимое, а `size()` вектора не изменился (проверено: `new_end - begin == 2`, но `size() == 4`). Чтобы реально убрать хвост, вызывают `erase(new_end, end())`. Связка «remove + erase» называется **идиомой erase-remove**:

```cpp
std::vector<int> n = {1, 2, 3, 2, 4, 2};
n.erase(std::remove(n.begin(), n.end(), 2), n.end());   // n: 1 3 4
```

> [!note] C++20
> В C++20 появились `std::erase(v, value)` и `std::erase_if(v, pred)`, которые делают обе операции за один вызов.

### std::unique

`std::unique` убирает **подряд идущие** дубликаты по тому же принципу (сдвиг + возврат нового конца):

```cpp
std::vector<std::string> animals = {"dog", "lama", "cat", "cat", "dog"};
animals.erase(std::unique(animals.begin(), animals.end()), animals.end());
// animals: dog lama cat dog   (одиночные "dog" не соседние — остались оба)
```

Чтобы убрать все дубликаты, данные сначала сортируют: `sort` + `unique` + `erase`.

## Полный проверенный пример

```cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>

int main()
{
    std::vector<std::string> an = {"dog", "lama", "cat", "tortoise"};
    auto new_end = std::remove_if(an.begin(), an.end(),
        [](const std::string& a) { return a[1] == 'o'; });
    std::cout << (new_end - an.begin()) << " " << an.size() << "\n";  // Вывод: 2 4
    an.erase(new_end, an.end());
    for (auto& x : an) std::cout << x << " ";                          // Вывод: lama cat
    std::cout << "\n";

    std::vector<int> v = {5, 3, 5, 1, 3, 3};
    std::sort(v.begin(), v.end());                                     // 1 3 3 3 5 5
    v.erase(std::unique(v.begin(), v.end()), v.end());                 // 1 3 5
    for (int x : v) std::cout << x << " ";                             // Вывод: 1 3 5
    std::cout << "\n";
}
```

## Задачи для практики

- Удалить из вектора чисел все отрицательные. *Решение:* `erase(remove_if(..., [](int x){return x < 0;}), end)`.
- Развернуть вектор без `std::reverse`, обходя `rbegin()..rend()` и записывая в новый. *Решение:* `std::vector<int> r(v.rbegin(), v.rend());`.
- Найти в `std::list` элемент и вставить после него новое значение. *Решение:* `auto it = find(...); if (it != end) l.insert(std::next(it), x);`.

## Частые ошибки

- Разыменование `end()` — это позиция за последним элементом.
- `remove`/`remove_if`/`unique` без последующего `erase` — размер контейнера не меняется, в хвосте мусор.
- Использование итератора после `insert`/`erase`/`push_back` (инвалидация).
- `it + n` для `set`, `list`, `map` — не компилируется; нужен `std::advance`/`std::next`.
- Использование `std::find` результата без проверки на `end()`.
- `unique` на несортированных данных удаляет только соседние дубликаты.

## Кратко (шпаргалка)

| Что | Запись |
|---|---|
| Диапазон | `[begin, end)` |
| Обход | `for (auto it = c.begin(); it != c.end(); ++it)` |
| Только чтение | `cbegin()/cend()`, `const_iterator` |
| С конца | `rbegin()/rend()` |
| Сдвиг для любых итераторов | `std::advance`, `std::next`, `std::prev`, `std::distance` |
| Удалить по условию | `c.erase(std::remove_if(c.begin(), c.end(), pred), c.end())` |
| Убрать дубликаты | `sort` + `erase(unique(...), end)` |
