# Структуры и перечисления

> [!abstract] О чём заметка
> Перечисления (`enum`) задают небольшой набор именованных констант, а структуры (`struct`) позволяют объединить разнородные данные в один пользовательский тип. Это первые шаги к созданию собственных типов, которые затем разовьются в [[02 Классы и объекты|классы]].

## Перечисления (enum)

Иногда переменная может принимать лишь ограниченный набор значений: четыре времени года, двенадцать месяцев, направления движения. Для таких данных придуманы перечисления.

> [!note] Определение
> **Перечисление (enumeration)** — это связанный набор именованных констант.

Объявляется ключевым словом `enum`. В курсе перечисления принято объявлять **вне функций** — в начале файла или в заголовке, чтобы тип был виден всему коду (технически C++ разрешает и локальные перечисления, но тогда их не передать в другую функцию).

```cpp
enum seasons
{
    spring,
    summer,
    autumn,
    winter
};

seasons season = spring;            // значение без квалификатора
seasons season2 = seasons::summer;  // значение с указанием типа (лучше так)
```

> [!note] Синтаксис
> `enum <название> { значение1, значение2, ..., значениеN };` — название задаёт новый тип, а список в фигурных скобках перечисляет все значения, которые может принять переменная этого типа. После `}` нужна `;`.

Указывать имя перечисления перед значением (`seasons::summer`) — хорошая привычка: код читается однозначнее, видно, к какому набору относится константа.

### enum class — «строгое» перечисление

Чтобы закрепить эту привычку, ввели квалификатор `class`: `enum class seasons { ... }`. Для него писать `seasons::spring` **обязательно**, голое `spring` не скомпилируется (`'spring' was not declared in this scope`). Кроме того, значения `enum class` не превращаются в числа неявно.

У обычного `enum` имена констант попадают прямо во внешнюю область видимости (см. [[10 Область видимости и пространства имён]]): два перечисления в одном файле не могут содержать одинаковое имя `Red`. У `enum class` константы живут «внутри» типа, поэтому `Color::Red` и `Light::Red` спокойно соседствуют.

```cpp
enum class Season { Spring, Summer, Autumn, Winter };

Season s = Season::Summer;
```

> [!tip] Совет
> По умолчанию используйте `enum class` — это безопаснее: имена констант не «протекают» во внешнюю область видимости и случайно не смешиваются с целыми числами.

### Что лежит внутри

Каждая константа перечисления — это целое число (отсюда и название: значения «перечисляются»). По умолчанию первая равна `0`, каждая следующая на единицу больше. Но **тип перечисления и `int` — не одно и то же**:

| Свойство | `enum` | `enum class` |
|---|---|---|
| Запись значения | `spring` или `seasons::spring` | только `seasons::spring` |
| Вывод в `cout` | печатает число (неявное преобразование в `int`) | **ошибка компиляции** |
| Неявное `int` → enum | нельзя | нельзя |
| Явное преобразование | `static_cast` | `static_cast` |

```cpp
#include <iostream>

enum class Season { Spring, Summer, Autumn, Winter };

int main()
{
    Season s = Season::Summer;
    // std::cout << s;                        // ошибка: нет оператора << для enum class
    std::cout << static_cast<int>(s) << "\n"; // Вывод: 1

    // Season x = 1;                          // ошибка: int не превращается в enum неявно
    Season t = static_cast<Season>(3);        // явное преобразование число -> enum
    if (t == Season::Winter)
        std::cout << "Зима\n";                // Вывод: Зима
}
```

Для обычного `enum` дело обстоит иначе: оно неявно преобразуется в `int`, поэтому `std::cout << spring;` печатает `0`, а `int n = winter;` даёт `3`. Обратно, из `int` в любой enum, неявно не получится — только `static_cast`.

```cpp
enum seasons { spring, summer, autumn, winter };

int main()
{
    std::cout << seasons::spring << "\n";  // Вывод: 0
    std::cout << seasons::summer << "\n";  // Вывод: 1
    std::cout << seasons::autumn << "\n";  // Вывод: 2
    std::cout << seasons::winter << "\n";  // Вывод: 3
    // seasons x = 1;                      // ошибка: invalid conversion from 'int' to 'seasons'
}
```

Запрет на неявные преобразования нужен для безопасности типов: чтобы значение перечисления случайно не оказалось в функции, ожидающей обычное число.

> [!warning] Осторожно с `static_cast<Enum>(число)`
> Компилятор не проверяет, что число соответствует какой-либо константе. `static_cast<Season>(42)` скомпилируется, но смысла в таком значении нет. Проверяйте диапазон сами.

### Пользовательские значения

Любой константе можно задать значение явно; следующие без значения продолжают счёт от предыдущей.

```cpp
enum seasons { spring = 1, summer, autumn, winter };
// spring = 1, summer = 2, autumn = 3, winter = 4

enum Temp { Zero, Hot = 4, Cold = -2, Freeze };
// Zero = 0, Hot = 4, Cold = -2, Freeze = -1   (Freeze продолжает счёт от Cold)

enum Dup { a, b, c = 0, d };
// a = 0, b = 1, c = 0, d = 1                  (значения совпали)
```

Значения не обязаны возрастать и даже могут совпадать, но так делать не стоит — легко запутаться: `a == c` будет истиной.

### Типичное использование

Чаще всего перечисления нужны для сравнений и выбора ветки (`if`, `switch`), см. [[02 Ветвления и логические операции]]:

```cpp
Season s = Season::Summer;
if (s == Season::Summer)
    std::cout << "На дворе лето!\n";  // Вывод: На дворе лето!

switch (s)
{
    case Season::Winter: std::cout << "холодно\n"; break;
    case Season::Summer: std::cout << "тепло\n";   break;  // сработает эта ветка
    default: break;
}
```

Если нужно получить из значения читаемую строку, пишут вспомогательную функцию со `switch` — сам `enum class` напечатать «по имени» язык не умеет:

```cpp
const char* to_text(Season s)
{
    switch (s)
    {
        case Season::Spring: return "весна";
        case Season::Summer: return "лето";
        case Season::Autumn: return "осень";
        case Season::Winter: return "зима";
    }
    return "?";
}
```

## Структуры (struct)

Допустим, программа хранит данные о сотрудниках. Держать отдельные массивы фамилий, имён и возрастов неудобно: данные одного человека связаны лишь совпадающим индексом, и эта связь легко ломается (отсортировали один массив — остальные «поехали»). Хотелось бы единого типа «сотрудник». Заранее все возможные типы язык предусмотреть не может, поэтому C++ даёт инструменты создания собственных типов: структуры и классы.

> [!note] Определение
> **Структура (struct)** — пользовательский тип данных, объединяющий разнородные данные. Данные внутри структуры называются **полями** (field); каждое поле — как переменная, существующая в рамках структуры.

Есть **определение** структуры (описание полей) и **экземпляры** (instances) — переменные этого типа.

```cpp
struct person
{
    std::string first_name;
    std::string last_name;
    int age;
};   // точка с запятой после } обязательна
```

### Создание экземпляров и инициализация

Экземпляр создаётся как обычная переменная: указываем тип и имя. Сразу заполнить поля можно **списком инициализации** в фигурных скобках — значения идут в том порядке, в каком поля объявлены в структуре.

```cpp
person p;                              // поля не заданы
person q = {"Дмитрий", "Иванов", 20};  // список инициализации
```

> [!warning] Поля простых типов не обнуляются
> У `person p;` поле `age` (типа `int`) содержит мусор, пока вы ничего не записали. Строки инициализируются пустой строкой. Чтобы избежать неопределённых значений, используйте список инициализации или значения по умолчанию в определении: `int age = 0;` (C++11).

### Доступ к полям

Через точку: `экземпляр.поле`. Поле можно и записывать, и читать.

```cpp
#include <iostream>
#include <string>

struct person
{
    std::string first_name;
    std::string last_name;
    int age;
};

int main()
{
    person p;
    p.first_name = "Дмитрий";
    p.last_name = "Иванов";
    p.age = 20;
    std::cout << p.first_name << " " << p.last_name << " " << p.age << "\n";
    // Вывод: Дмитрий Иванов 20
}
```

### Доступ через указатель

Экземпляр лежит в памяти и имеет адрес, поэтому можно взять `&` и получить указатель на структуру (см. [[07 Указатели и массивы]]). Есть два способа добраться до полей:

- разыменовать и поставить точку: `(*p_pers).last_name` (скобки обязательны: у `.` приоритет выше, чем у `*`);
- **оператор стрелка `->`** — удобная краткая запись: `p_pers->last_name`.

```cpp
person pers = {"Василий", "Чапаев", 20};
person* p_pers = &pers;
(*p_pers).first_name = "Дмитрий";  // через * и .
p_pers->last_name = "Иванов";      // через ->
// pers теперь: Дмитрий Иванов 20
```

> [!tip] Откуда берётся стрелка
> `p->x` — это ровно то же самое, что `(*p).x`. Скобки в длинной записи обязательны: у `.` приоритет выше, чем у `*`, и без скобок `*p.x` читалось бы как `*(p.x)`.

### Структуры и функции

Структуры можно передавать в функции и возвращать из них. При передаче **по значению** внутри функции создаётся копия, поэтому изменения полей исходного экземпляра не затрагивают. Чтобы функция меняла оригинал, передают ссылку или указатель.

```cpp
void inc_value(person p)  { p.age++;  }  // копия: оригинал не меняется
void inc_ref(person& p)   { p.age++;  }  // ссылка: оригинал меняется
void inc_ptr(person* p)   { p->age++; }  // указатель: оригинал меняется

int main()
{
    person pers = {"Иван", "Петров", 20};
    inc_value(pers);  // pers.age == 20
    inc_ref(pers);    // pers.age == 21
    inc_ptr(&pers);   // pers.age == 22
}
```

> [!tip] Совет
> Крупные структуры (со строками, массивами) лучше передавать по ссылке, даже если менять их не нужно — иначе копируются все поля. Если менять не требуется, используйте `const person&`.

### Массивы структур

Структуры можно хранить в массивах, в том числе динамических (см. [[08 Указатели и динамическая память]]):

```cpp
person* people = new person[20];
people[0].first_name = "Анатолий";
people[0].last_name = "Петров";
people[0].age = 20;
std::cout << people[0].first_name << " " << people[0].last_name
          << " " << people[0].age << "\n";  // Анатолий Петров 20
delete[] people;  // каждому new[] — свой delete[]
```

Или статически, сразу с инициализацией каждого элемента, и обойти циклом (см. [[04 Массивы]], [[03 Циклы]]):

```cpp
person staff[2] = {{"Анна", "Лебедева", 28}, {"Олег", "Громов", 35}};
for (const person& p : staff)
    std::cout << p.first_name << " " << p.last_name << " " << p.age << "\n";
// Вывод:
// Анна Лебедева 28
// Олег Громов 35
```

## Совместное использование: enum внутри struct

Перечисления и структуры отлично работают вместе: поле-перечисление ограничивает набор допустимых значений.

```cpp
#include <iostream>
#include <string>

enum class Position { Intern, Developer, Manager };

struct Employee
{
    std::string name;
    int age = 0;
    Position position = Position::Intern;
};

int main()
{
    Employee e = {"Анна", 28, Position::Developer};
    if (e.position == Position::Developer)
        std::cout << e.name << " — разработчик\n";  // Анна — разработчик
}
```

Такой код проверяется на ошибки: переменной `Employee::position` нельзя присвоить произвольное число, и опечатка в имени должности — ошибка компиляции, а не «молчаливое» значение `"devloper"` в строке. Пример целиком (с функцией `to_string` и значениями по умолчанию):

```cpp
#include <iostream>
#include <string>

enum class Position { Intern, Developer, Manager };

std::string to_string(Position p)
{
    switch (p)
    {
        case Position::Intern:    return "стажёр";
        case Position::Developer: return "разработчик";
        case Position::Manager:   return "руководитель";
    }
    return "?";
}

struct Employee
{
    std::string name;
    int age = 0;                                 // значения по умолчанию (C++11)
    Position position = Position::Intern;
};

int main()
{
    Employee e = {"Анна", 28, Position::Developer};
    Employee n;
    n.name = "Олег";
    std::cout << e.name << " — " << to_string(e.position) << "\n";
    std::cout << n.name << " — " << to_string(n.position)
              << ", возраст " << n.age << "\n";
}
// Вывод:
// Анна — разработчик
// Олег — стажёр, возраст 0
```

> [!note] Замечание о списках инициализации
> Запись `Employee e = {"Анна", 28, ...}` для структуры сначальными значениями полей (`int age = 0;`) работает начиная с C++14; в C++11 такая структура уже не считается «агрегатом». Опция `-std=c++17` из курса это допускает.

## Частые ошибки

- Забыть `;` после закрывающей `}` определения структуры или перечисления.
- Пытаться вывести `enum class` через `cout` без `static_cast<int>`.
- Присваивать число переменной типа перечисления без явного приведения.
- Ожидать, что функция изменит структуру, переданную по значению.
- Использовать неинициализированные поля простых типов.
- Объявлять `enum` внутри функции и потом пытаться использовать его в другой функции: тип виден только там, где объявлен.
- Давать константам одного обычного `enum` и разных перечислений одинаковые имена (конфликт имён) — для этого и нужен `enum class`.

## Кратко (шпаргалка)

| Что | Синтаксис |
|---|---|
| Перечисление | `enum class E { a, b, c };` |
| Значение | `E::a` |
| enum → int | `static_cast<int>(e)` |
| int → enum | `static_cast<E>(1)` |
| Явные значения | `enum E { a = 1, b, c = 10 };` |
| Структура | `struct S { int x; std::string s; };` |
| Инициализация | `S v = {1, "text"};` |
| Поле | `v.x`, через указатель `p->x` |
| Передача для изменения | `S&` или `S*` |

## Задачи для практики

1. Опишите `enum class Direction { North, East, South, West }` и функцию `Direction turn_right(Direction d)`. Решение: `return static_cast<Direction>((static_cast<int>(d) + 1) % 4);`.
2. Создайте структуру `point { double x, y; }` и функцию `double dist(const point& a, const point& b)` (понадобится `std::sqrt` из `<cmath>`).
3. Заведите массив из пяти `person`, заполните его и напишите функцию, которая находит самого старшего (возвращает указатель на элемент массива).
4. Напишите функцию `void birthday(person& p)`, которая увеличивает возраст, и проверьте, что вариант `void birthday(person p)` ничего не меняет.
