# Строки

> [!abstract] О чём заметка
> В C++ есть два способа работать с текстом: «сишные» строки — массивы символов `char` с нуль-терминатором и функции из `<cstring>`, и удобный класс `std::string`, который сам управляет памятью. Разберём, как устроены символы и таблица ASCII, как работают строковые функции и почему в повседневном коде почти всегда лучше `std::string`.

## Что такое строка

**Строка — это массив символов.** Символ в C++ представлен типом `char`. Фактически `char` — это **целое число размером 1 байт** (256 возможных значений). Чтобы число превратилось в букву, используется **таблица ASCII**, которая сопоставляет код символа самому символу.

Коды в таблицах обычно приводят в шестнадцатеричной записи. Несколько опорных значений:

| Символ | Код (hex) | Код (dec) |
|---|---|---|
| `N` | 4E | 78 |
| `d` | 64 | 100 |
| `k` | 6B | 107 |
| `0` (цифра) | 30 | 48 |
| `A` | 41 | 65 |
| `a` | 61 | 97 |
| NUL (конец строки) | 00 | 0 |

> [!warning] Не путайте
> Символ `'0'` (код 48) и число 0 — разные вещи. Символ-терминатор `'\0'` имеет код 0.

Положить в `char` можно как число, так и символ в одинарных кавычках, а чтобы увидеть код, нужно привести значение к `int` (о `static_cast` см. [[05 Функции и рекурсия]]):

```cpp
#include <iostream>

int main()
{
    char ch = 78;                                    // число 78 — это код буквы N
    std::cout << ch << std::endl;                    // Вывод: N

    char k = 107;
    std::cout << k << std::endl;                     // Вывод: k

    char letter = 'N';
    std::cout << static_cast<int>(letter) << std::endl;   // Вывод: 78
    return 0;
}
```

Так как символы — числа, с ними можно считать: `'a' + 1` равно `'b'`, а `'7' - '0'` даёт число 7.

## Строка как массив char

```cpp
char str[] = { "Hello" };   // можно и проще: char str[] = "Hello";
```

`str` — обычный автоматический массив (см. [[04 Массивы]]). Узнаем число его элементов: размер всего массива делим на размер элемента.

```cpp
#include <iostream>

int main()
{
    char str[] = { "Hello" };
    std::cout << str << std::endl;                          // Вывод: Hello
    int size = sizeof(str) / sizeof(str[0]);
    std::cout << size << std::endl;                         // Вывод: 6

    for (int i = 0; i < size; i++)
    {
        std::cout << "str[" << i << "] = " << str[i]
                  << ". Code = " << static_cast<int>(str[i]) << std::endl;
    }
    return 0;
}
```

В слове `Hello` 5 букв, а элементов 6. Последний, шестой, имеет код 0 и не печатается — это **нуль-терминатор** (NUL, `'\0'`).

```text
индекс:   0    1    2    3    4    5
символ:  'H'  'e'  'l'  'l'  'o'  '\0'
код:      72  101  108  108  111   0
```

> [!note] Нуль-терминатор
> **Нуль-терминатор** — служебный символ с кодом 0, обозначающий конец строки. Благодаря ему функциям, работающим со строками, достаточно передать только указатель на начало (см. [[07 Указатели и массивы]]): они идут по символам, пока не встретят `'\0'`. Длину строки передавать не нужно.

Из-за терминатора под строку из $n$ символов нужен массив минимум из $n + 1$ элементов.

## Функции из `<cstring>` и `<cstdlib>`

Для «сишных» строк есть набор функций из библиотеки `<cstring>`:

| Функция | Что делает |
|---|---|
| `strlen` | длина строки (без терминатора) |
| `strcpy` | копирует одну строку в другую |
| `strcat` | приклеивает одну строку к концу другой |
| `strcmp` | сравнивает две строки |
| `strchr` | ищет первое вхождение символа |
| `atoi`, `atol`, `atof` | превращают строку в `int`, `long`, `double` (в `<cstdlib>`) |

### strlen

Считает символы **без** терминатора. Сигнатура: `size_t strlen(const char* str)`.

```cpp
#include <iostream>
#include <cstring>

int main()
{
    char str[] = { "Hello" };
    std::cout << strlen(str) << std::endl;   // Вывод: 5 (а sizeof(str) == 6)
    return 0;
}
```

### strcpy

`char* strcpy(char* destination, const char* source)` копирует `source` в `destination` вместе с терминатором и возвращает `destination`. Массив `destination` **обязан быть достаточно большим**.

```cpp
#include <iostream>
#include <cstring>

int main()
{
    char source[] = { "Hello" };
    char dest[10];
    std::cout << strcpy(dest, source) << std::endl;   // Вывод: Hello
    return 0;
}
```

### strcat

`char* strcat(char* destination, const char* source)` дописывает `source` в конец `destination`: терминатор `destination` затирается первым символом `source`, а новый терминатор ставится в конце. Место в `destination` должно вмещать итоговую строку. (В слайдах сигнатура `strcat` ошибочно названа `strcpy`; на деле это отдельная функция.)

```cpp
#include <iostream>
#include <cstring>

int main()
{
    char source[] = { " world" };
    char dest[30] = { "Hello" };
    std::cout << strcat(dest, source) << std::endl;   // Вывод: Hello world
    return 0;
}
```

### strcmp

Сравнивает строки посимвольно (по кодам) и возвращает отрицательное число, если первая «меньше», **0** при равенстве и положительное, если первая «больше».

```cpp
#include <iostream>
#include <cstring>

int main()
{
    char str1[] = { "Hello" };
    char str2[] = { "Hi" };
    char str3[] = { "Hello" };

    std::cout << (strcmp(str1, str2) < 0) << std::endl;   // Вывод: 1 ("Hello" < "Hi", т.к. 'e' < 'i')
    std::cout << (strcmp(str2, str3) > 0) << std::endl;   // Вывод: 1
    std::cout << strcmp(str1, str3) << std::endl;         // Вывод: 0
    return 0;
}
```

> [!warning] Не полагайтесь на конкретное значение
> Стандарт гарантирует только знак результата. На разных компиляторах `strcmp` может вернуть `-1`, `-5` или `-97`; в слайдах `-1` и `1` — частный случай. Проверяйте `< 0`, `== 0`, `> 0`.

Именно поэтому `str1 == str2` для массивов `char` **не сравнивает строки**: сравниваются адреса. Для текста нужен `strcmp`.

### strchr

`char* strchr(const char* str, int ch)` ищет символ и возвращает **указатель** на его первое вхождение; если символа нет — `nullptr`. Вывод такого указателя печатает «хвост» строки от найденного символа.

```cpp
#include <iostream>
#include <cstring>

int main()
{
    char str[] = { "Hello" };
    char* found = strchr(str, 'e');
    std::cout << found << std::endl;                    // Вывод: ello
    std::cout << (found - str) << std::endl;            // Вывод: 1 (позиция символа)
    std::cout << (strchr(str, 'z') == nullptr) << std::endl;   // Вывод: 1 (не найден)
    return 0;
}
```

### atoi, atol, atof

Превращают строку в число: `atoi` — в `int`, `atol` — в `long`, `atof` — в `double`. При неудаче возвращают 0 (то есть отличить «не число» от настоящего нуля нельзя). В слайдах для `atol` и `atof` по ошибке вызывается `atoi`; правильно так:

```cpp
#include <iostream>
#include <cstdlib>

int main()
{
    char num[] = { "123" };
    char real[] = { "123.52" };
    char bad[] = { "Hello" };

    std::cout << atoi(num) << std::endl;     // Вывод: 123
    std::cout << atol(num) << std::endl;     // Вывод: 123
    std::cout << atof(real) << std::endl;    // Вывод: 123.52
    std::cout << atoi(bad) << std::endl;     // Вывод: 0 (преобразование не удалось)
    return 0;
}
```

## Тип std::string

Работать с массивами `char` неудобно: нужно следить за размером, терминатором и переполнением. Поэтому в C++ есть тип **`std::string`** (заголовок `<string>`, пространство имён `std`, см. [[10 Область видимости и пространства имён]]).

### Инициализация

Все способы равноправны:

```cpp
#include <iostream>
#include <string>

int main()
{
    char str0[] = { "Hello0" };
    std::string str1 = { "Hello1" };
    std::string str2 { "Hello2" };
    std::string str3("Hello3");
    std::string str4 = "Hello4";
    std::string str5 = str4;      // из другой std::string
    std::string str6 = str0;      // из «сишной» строки

    std::cout << str5 << std::endl;   // Вывод: Hello4
    std::cout << str6 << std::endl;   // Вывод: Hello0
    return 0;
}
```

### Память управляется сама

`std::string` сам работает с динамической памятью (см. [[08 Указатели и динамическая память]]), поэтому в него поместится строка любой длины, например, из пользовательского ввода. С обычным массивом так не получится:

```cpp
char* name_unalloc;        // указатель в никуда: память не выделена
char name_char[30];        // вместит не более 29 символов (1 место — под NUL)
std::string name_string;   // вместит имя любой длины

// std::cin >> name_unalloc;  // нельзя: писать некуда — неопределённое поведение
// std::cin >> name_char;     // опасно: длинное имя выйдет за границы массива
// std::cin >> name_string;   // безопасно
```

### Основные операции

| Операция | Запись | Результат |
|---|---|---|
| длина | `s.length()` (или `s.size()`) | число символов |
| копирование | `b = a;` | независимая копия |
| конкатенация | `a + b`, `a += b` | склеенная строка |
| сравнение | `a == b`, `a.compare(b)` | равенство / знак |
| поиск | `s.find(x)` | позиция или `std::string::npos` |
| в число | `std::stoi`, `stol`, `stof`, `stod` | число |

Функции вида `s.length()` принадлежат самому объекту строки, поэтому вызываются через точку (подробнее — в [[02 Классы и объекты]]).

```cpp
#include <iostream>
#include <string>

int main()
{
    std::string name = "Anton";
    std::cout << name.length() << std::endl;       // Вывод: 5

    // копирование — простое присваивание, копия независима
    std::string copy = name;
    copy[0] = 'E';                                  // к символам обращаемся по индексу
    std::cout << name << std::endl;                 // Вывод: Anton
    std::cout << copy << std::endl;                 // Вывод: Enton

    // конкатенация
    std::string str1 = "Hello";
    std::string str2 = " world";
    std::string str3 = str1 + str2;
    str1 += str2;
    std::cout << str1 << std::endl;                 // Вывод: Hello world
    std::cout << str3 + " again!" << std::endl;     // Вывод: Hello world again!
    return 0;
}
```

> [!note] Ввод слова и строки
> `std::cin >> s` читает только до первого пробела. Чтобы прочитать целую строку с пробелами, используют `std::getline(std::cin, s);`.

**Сравнение.** Оператор `==` возвращает `true` (в `cout` печатается 1) или `false` (0). Метод `compare` возвращает число со знаком, как `strcmp`:

```cpp
#include <iostream>
#include <string>

int main()
{
    std::string str1 = "Hello";
    std::string str2 = "Hi";
    std::string str3 = "Hello";

    std::cout << (str1.compare(str2) < 0) << std::endl;   // Вывод: 1 (str1 меньше)
    std::cout << (str2.compare(str3) > 0) << std::endl;   // Вывод: 1
    std::cout << str1.compare(str3) << std::endl;         // Вывод: 0
    std::cout << (str1 == str2) << std::endl;             // Вывод: 0
    std::cout << (str1 == str3) << std::endl;             // Вывод: 1
    return 0;
}
```

Также работают `<`, `>`, `<=`, `>=` — в лексикографическом порядке.

**Поиск.** `find` принимает символ или подстроку и возвращает позицию первого вхождения (с нуля). Если не нашлось, возвращается специальное значение `std::string::npos`:

```cpp
#include <iostream>
#include <string>

int main()
{
    std::string str = "Hello";
    std::cout << str.find('e') << std::endl;                       // Вывод: 1
    std::cout << str.find("lo") << std::endl;                      // Вывод: 3
    std::cout << (str.find("Hi") == std::string::npos) << std::endl;   // Вывод: 1 (не найдено)
    return 0;
}
```

**Преобразование в число.** `std::stoi` (в `int`), `std::stol` (в `long`), `std::stof` (в `float`), `std::stod` (в `double`). В отличие от `atoi`, при ошибке они выбрасывают исключение (подробнее — в [[06 Исключения и обработка ошибок]]):

```cpp
#include <iostream>
#include <string>

int main()
{
    std::string str = "123";
    std::cout << std::stoi(str) << std::endl;        // Вывод: 123
    std::cout << std::stod("3.14") + 1 << std::endl; // Вывод: 4.14
    return 0;
}
```

> [!tip] Какой тип выбрать
> В обычных программах используйте `std::string`. Массивы `char` и `<cstring>` нужны для работы со старым кодом и C-библиотеками. Из `std::string` получить «сишную» строку можно методом `c_str()`.

## Задачи для практики

1. **Код символа.** Прочитайте символ и выведите его код. Решение: `char c; std::cin >> c; std::cout << static_cast<int>(c);`.
2. **Подсчёт гласных** в строке: цикл по индексам `s[i]`, сравнение с набором `'a','e','i','o','u'`.
3. **Палиндром:** строка совпадает с собой, прочитанной с конца. Два индекса: `i` с начала, `j` с конца, пока `i < j` сравниваем `s[i]` и `s[j]`.
4. **Длина без `strlen`:** пройти по `char`-массиву до `'\0'`, считая шаги.

## Частые ошибки

- Забыть про `'\0'`: массив `char name[5]` не вместит `"Hello"` (нужно 6).
- `strcpy`/`strcat` в слишком маленький массив — выход за границы (переполнение буфера).
- Сравнивать «сишные» строки через `==` — сравниваются адреса, а не содержимое.
- Читать ввод в указатель без выделенной памяти.
- Рассчитывать на конкретные значения `strcmp` (`-1`/`1`), а не на знак.
- Путать `'a'` (символ) и `"a"` (строка из двух элементов: `'a'` и `'\0'`).

## Кратко (шпаргалка)

- `char` — целое число в 1 байт; соответствие чисел и символов задаёт таблица ASCII.
- «Сишная» строка — `char`-массив, заканчивающийся `'\0'`; размер массива = длина + 1.
- `<cstring>`: `strlen`, `strcpy`, `strcat`, `strcmp`, `strchr`; `<cstdlib>`: `atoi`, `atol`, `atof`.
- `std::string`: сам выделяет память, поддерживает `=`, `+`, `+=`, `==`, `.length()`, `.find()`, `.compare()`, `std::stoi/stod`.
- Не найдено: `strchr` даёт `nullptr`, `find` даёт `std::string::npos`.
