# Модель памяти

> [!abstract] О чём заметка
> Что на самом деле происходит, когда мы пишем `int number;`: как устроена память компьютера, как узнать адрес (`&`) и размер (`sizeof`) переменной, почему функция получает *копию* аргумента и как передать переменную по ссылке, чтобы функция могла изменить оригинал.

## Как устроена память

**Память — это набор пронумерованных ячеек.** Каждая ячейка хранит 1 байт (8 бит) и имеет свой **адрес** — число, обычно записываемое в шестнадцатеричной (HEX) форме: `0xFE0`, `0x0054F7DC`. В десятичной системе это тот же номер (`0xFE0` = 4064).

```text
Переменная    a      b      val (занимает 4 ячейки)      c1   c2   c3
Значение      54     22     4511                          H    e    i
Адрес (HEX)   0xFE0  0xFE1  0xFE2 0xFE3 0xFE4 0xFE5      0xFE6 0xFE7 0xFE8
```

Когда мы создаём переменную, операционная система (ОС) выделяет под неё свободный участок памяти. Если значение типа не помещается в одну ячейку, переменная занимает **несколько ячеек подряд**, а её адресом считается **адрес первой из них**. У каждой переменной свой адрес.

## Адрес переменной: оператор `&`

**Оператор взятия адреса `&`**, поставленный перед именем, возвращает адрес первой ячейки переменной:

```cpp
#include <iostream>

int main()
{
    int number = 57;
    std::cout << &number << std::endl;   // Вывод (пример): 0x7ffd1c2a9b3c
    return 0;
}
```

Адрес печатается в HEX. При **каждом запуске** программы он будет другим: ОС выдаёт программе разные участки оперативной памяти.

> [!warning] Что нельзя
> `&` применяется только к тому, что **лежит в памяти и имеет имя**: к переменным (и функциям). Литерал вроде `&5` взять нельзя.

## Размер переменной: оператор `sizeof`

**`sizeof` возвращает размер в байтах**, то есть число ячеек, которые занимает значение. Его можно применять и к переменной, и к типу. Размер зависит только от типа и не меняется от запуска к запуску (в отличие от адреса).

```cpp
#include <iostream>

int main()
{
    int number;
    double d1, d2;
    std::cout << sizeof(number) << '\n';   // 4
    std::cout << sizeof(int)    << '\n';   // 4
    std::cout << sizeof(d1)     << '\n';   // 8
    std::cout << sizeof(double) << '\n';   // 8
    return 0;
}
```

Типичные размеры на современных 64-битных системах: `char` — 1, `bool` — 1, `int` — 4, `double` — 8 байт. Стандарт гарантирует не точные числа, а лишь минимумы, поэтому на другой платформе значения могут отличаться.

Теперь можно нарисовать `int number = 57;` целиком: переменная начинается с адреса `0x0054F7DC` и занимает 4 ячейки — `…DC`, `…DD`, `…DE`, `…DF`.

## Переменные, объявленные подряд

Переменные, объявленные друг за другом, ОС размещает «примерно в одном месте», рядом друг с другом (но порядок и промежутки определяет компилятор):

```cpp
#include <iostream>

int main()
{
    int a = 60;
    double d = 120.5;
    int b = -70;
    std::cout << "a: " << &a << " " << sizeof(a) << '\n';
    std::cout << "d: " << &d << " " << sizeof(d) << '\n';
    std::cout << "b: " << &b << " " << sizeof(b) << '\n';
}
// Вывод (пример):
// a: 0x7fff42f9ca60 4
// d: 0x7fff42f9ca70 8
// b: 0x7fff42f9ca64 4
```

Видно, что адреса близки, но компилятор может переставить переменные (например, `b` оказалась рядом с `a`).

## Массив в памяти

**Элементы массива лежат в памяти последовательно, подряд**, а адрес массива совпадает с адресом его нулевого элемента.

```cpp
#include <iostream>

int main()
{
    const int size = 3;
    int arr[size] = {1, 2, 3};
    std::cout << "sizeof(arr) = " << sizeof(arr) << '\n';   // 12 = 3 * 4
    for (int i = 0; i < size; i++)
        std::cout << "arr[" << i << "]: " << &arr[i] << '\n';
}
// Вывод (пример): адреса отличаются ровно на 4 байта
// arr[0]: 0x7fff42f9ca7c
// arr[1]: 0x7fff42f9ca80
// arr[2]: 0x7fff42f9ca84
```

```text
arr[0]            arr[1]            arr[2]
| 1 | . | . | . | 2 | . | . | . | 3 | . | . | . |
..7C              ..80              ..84
```

Именно на этой последовательности держится арифметика указателей, см. [[07 Указатели и массивы]]. Подробнее про массивы: [[04 Массивы]].

## Присваивание копирует значение

```cpp
int num1 = 5;
int num2 = num1;   // значение из ячеек num1 скопировано в ячейки num2
```

У `num1` и `num2` **разные адреса**: это независимые ячейки, поэтому их значения потом можно менять независимо.

## Что происходит при вызове функции

**При вызове функции для каждого параметра создаётся новая переменная, в которую копируется переданное значение** (передача по значению). Поэтому изменения параметра не затрагивают исходную переменную:

```cpp
#include <iostream>

void calc(int x)
{
    x *= 10;
    std::cout << x << std::endl;       // 50
}

int main()
{
    int value = 5;
    calc(value);
    std::cout << value << std::endl;   // 5: value не изменилась
    return 0;
}
```

Если вывести `&x` внутри `calc` и `&value` в `main`, адреса будут разными: это две разные переменные.

Возникает вопрос: как изменить из функции переменную, принадлежащую другой функции? Такой код не скомпилируется:

```cpp
void calc()
{
    value *= 10;   // ошибка: имя value здесь неизвестно
}

int main()
{
    int value = 5;
    calc();
}
```

Причина — область видимости.

## Область видимости

**Переменная доступна только в блоке, где она объявлена (и во вложенных блоках), и только после точки объявления.** Блок — это код между `{` и `}`. Параметры функции доступны в любом месте функции.

```cpp
#include <iostream>

int main(int argc, char** argv)
{
    int x = 5;            // x доступна до конца main
    {
        int value = 7;    // вложенный блок
        std::cout << value << std::endl;   // 7
    }                     // value здесь «умирает»
    // std::cout << value;  // ошибка: value уже недоступна
    return 0;
}
```

Подробнее о видимости, `static` и пространствах имён: [[10 Область видимости и пространства имён]].

### Глобальные переменные: плохое решение

Можно вынести переменную за пределы всех функций, тогда её увидят все:

```cpp
#include <iostream>

int value;                // глобальная переменная

void calc() { value *= 10; }

int main()
{
    value = 5;
    calc();
    std::cout << value << std::endl;   // 50
}
```

Работает, но **глобальные переменные — почти всегда проблема**: доступ к ним не контролируется, их может изменить кто угодно и когда угодно, и гарантий, что значение не испорчено, нет. Бывают редкие оправданные случаи, но общее правило: *если хочется глобальную переменную, скорее всего, ошибка в проектировании кода*.

## Как обойтись без глобальных переменных

**Вариант 1: вернуть значение из функции** и присвоить его там, откуда вызывали:

```cpp
int calc(int value) { return value * 10; }

int main()
{
    int value = 5;
    value = calc(value);   // 50
}
```

**Вариант 2: передать по ссылке.** Подробнее ниже.

## Передача по ссылке

Если поставить `&` **сразу после имени типа** в параметре функции, параметр становится **ссылкой (reference)**: не новой переменной с копией, а ещё одним именем той же самой переменной.

```cpp
#include <iostream>

void calc(int& x)            // x — ссылка на переданную переменную
{
    x *= 10;
    std::cout << x << std::endl;       // 50
}

int main()
{
    int value = 5;
    calc(value);
    std::cout << value << std::endl;   // 50: изменилась и исходная переменная
    return 0;
}
```

> [!note] Два разных смысла `&`
> - `&name` в **выражении** — взять адрес переменной.
> - `Type& name` в **объявлении** (параметра, переменной) — ссылка.

Ещё пример: функция, меняющая местами два значения.

```cpp
#include <iostream>

void swapInts(int& a, int& b)
{
    int t = a;
    a = b;
    b = t;
}

int main()
{
    int p = 1, q = 2;
    swapInts(p, q);
    std::cout << p << ' ' << q << '\n';   // 2 1
}
```

> [!tip] Когда что выбирать
> Нужно только прочитать значение — передавайте по значению. Нужно изменить переменную вызывающего кода — по ссылке. Один результат проще вернуть через `return`.

Массивы в функции передаются иначе: об этом в [[07 Указатели и массивы]] и [[05 Функции и рекурсия]].

## Частые ошибки
- Ожидать, что функция `void f(int x)` изменит переменную вызывающего кода.
- Брать адрес литерала (`&5`) или рассчитывать, что адрес будет одинаковым между запусками.
- Считать, что `sizeof(int)` одинаков на всех платформах.
- Использовать переменную за пределами блока, где она объявлена.
- Заводить глобальную переменную «чтобы было проще».

## Кратко (шпаргалка)

| Что | Как |
|---|---|
| Адрес переменной | `&x` |
| Размер в байтах | `sizeof(x)` или `sizeof(тип)` |
| Элементы массива | лежат подряд, адреса растут на `sizeof(элемента)` |
| Передача по значению | `void f(int x)`: копия |
| Передача по ссылке | `void f(int& x)`: тот же объект |
| Область видимости | от объявления до конца блока `{}` |
