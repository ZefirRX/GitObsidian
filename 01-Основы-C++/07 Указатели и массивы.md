# Указатели и массивы

> [!abstract] О чём заметка
> Указатель — это переменная, которая хранит адрес ячейки памяти. С его помощью можно читать и менять чужие данные, не обращаясь к переменной по имени. Эта заметка объясняет операции `&` и `*`, указатели на указатели, а главное — связь указателей с массивами и три способа передать массив в функцию.

## Оператор typeid: узнаём тип

Прежде чем знакомиться с указателями, нужен инструмент, показывающий тип переменной или значения — оператор `typeid` (заголовок `<typeinfo>`):

```cpp
typeid(<переменная или литерал>).name()
```

```cpp
#include <iostream>
#include <typeinfo>

int main()
{
    double number = 5.6;
    std::cout << typeid(number).name() << std::endl;   // Вывод (g++): d
    std::cout << typeid(10.4).name() << std::endl;     // Вывод (g++): d  — литерал 10.4 имеет тип double
    std::cout << typeid(3).name() << std::endl;        // Вывод (g++): i  — литерал 3 имеет тип int
    return 0;
}
```

> [!note] Как читать вывод
> Запись `name()` зависит от компилятора. MSVC печатает `double` и `int`, а g++ и clang — сокращения: `d` (double), `i` (int), `Pi` (указатель на int), `PPi` (указатель на указатель на int).

## Адрес и указатель

Каждая переменная лежит в какой-то ячейке памяти, у которой есть адрес. Оператор **`&` (взятие адреса)** возвращает этот адрес. Логичная идея — сохранить его в `int`, но так не получится:

```cpp
int number = 5;
int address = &number;   // ошибка компиляции: тип &number — не int
```

Какой же тип у `&number`? Для `int` это `int *`. Запись `T *` — **тип «указатель на T»**.

> [!note] Указатель
> **Указатель (pointer)** — это переменная, значением которой является адрес ячейки памяти. Объявление: `<тип> * <имя>;`. Тип указателя хранит информацию о том, значение какого типа лежит по адресу: `int *` указывает на `int`, `double *` — на `double`.

```cpp
#include <iostream>

int main()
{
    int number = 5;
    int* p_number = &number;   // инициализация при объявлении
    int* p_number2;            // сначала объявили...
    p_number2 = &number;       // ...потом присвоили

    std::cout << "p_number:  " << p_number << std::endl;    // Вывод: адрес, например 0x7ffd5a3c
    std::cout << "p_number2: " << p_number2 << std::endl;   // тот же адрес
    return 0;
}
```

```text
 переменная number          указатель p_number
 +-----------------+        +----------------------+
 | 5               | <------| адрес number (0x...) |
 +-----------------+        +----------------------+
   адрес 0x7ffd5a3c
```

> [!tip] Где ставить звёздочку
> `int* p`, `int * p` и `int *p` — одно и то же. Но `int* a, b;` объявит **только `a`** указателем, а `b` будет обычным `int`.

> [!warning] Неинициализированный указатель
> `int* p;` содержит мусорный адрес. Если указателю пока нечего хранить, присвойте `nullptr` (нулевой указатель): `int* p = nullptr;`.

## Разыменование

Зачем хранить адрес? Чтобы по нему обращаться к содержимому ячейки — читать и изменять его. Это делает **оператор разыменования `*`** (dereference): пишется перед указателем.

Взятие адреса `&` и разыменование `*` — **обратные операции**: `*&number` — это снова `number`.

```cpp
#include <iostream>

int main()
{
    int number = 5;
    int* p_number = &number;

    std::cout << number << std::endl;       // Вывод: 5
    std::cout << *p_number << std::endl;    // Вывод: 5

    *p_number = 10;                         // меняем значение, не трогая имя number

    std::cout << number << std::endl;       // Вывод: 10
    std::cout << *p_number << std::endl;    // Вывод: 10
    std::cout << *&number << std::endl;     // Вывод: 10
    return 0;
}
```

Мы изменили `number`, ни разу не написав `number = ...`. Именно это и позволяет делать указатель: передав адрес в функцию, мы даём ей право менять наши данные.

> [!warning] Звёздочка значит разное
> В объявлении `int* p` звёздочка — часть **типа**. В выражении `*p` — операция **разыменования**. А `a * b` — умножение.

## Указатели на указатели

Указатель — тоже переменная, у неё есть адрес. Тип адреса переменной `int*` — это `int**` («указатель на указатель на int»).

```text
   int*** ppp --> int** pp --> int* p --> int number
                                          (значение 5)
```

Это можно продолжать сколько угодно: `int***` — указатель третьего порядка. Каждое разыменование «снимает» одну звёздочку:

```cpp
#include <iostream>

int main()
{
    int number = 5;
    int* p = &number;       // int*
    int** pp = &p;          // int**
    int*** ppp = &pp;       // int***

    std::cout << ppp << std::endl;     // адрес pp
    std::cout << *ppp << std::endl;    // значение pp, т.е. адрес p (тип int**)
    std::cout << **ppp << std::endl;   // значение p, т.е. адрес number (тип int*)
    std::cout << ***ppp << std::endl;  // Вывод: 5

    ***ppp = 77;                       // меняем number через цепочку указателей
    std::cout << number << std::endl;  // Вывод: 77
    return 0;
}
```

Разыменование указателя типа `int***` даёт значение типа `int**`: то, что лежит в ячейке по адресу, хранящемуся в указателе. Практически чаще всего встречаются `int*` и `int**` (например, двумерные динамические массивы, см. [[08 Указатели и динамическая память]]).

## Массив — это адрес первого элемента

Что будет, если вывести имя массива?

```cpp
#include <iostream>

int main()
{
    int arr[] = {5, 3, 4};
    std::cout << "arr: " << arr << std::endl;
    for (int i = 0; i < 3; i++)
    {
        std::cout << "&arr[" << i << "]: " << &arr[i] << std::endl;
    }
    return 0;
}
// Вывод (адреса условные):
// arr: 0x7ffc1000
// &arr[0]: 0x7ffc1000
// &arr[1]: 0x7ffc1004
// &arr[2]: 0x7ffc1008
```

Имя массива выводит адрес — и он совпадает с адресом первого элемента. Элементы лежат подряд, шаг равен размеру `int` (4 байта). То есть **имя массива в выражениях превращается в указатель на его первый элемент**.

```text
arr -->  [ 5 ][ 3 ][ 4 ]
         0x..00  0x..04  0x..08
```

Тонкость: массив — не совсем обычный указатель. Локальный массив «знает» свой размер, поэтому `sizeof(arr) / sizeof(arr[0])` даёт число элементов (см. [[04 Массивы]]). Но стоит передать массив в функцию — размер теряется (см. ниже). Динамические массивы устроены иначе — о них в [[08 Указатели и динамическая память]].

Из этого следует важный факт: `arr[i]` — это то же самое, что `*(arr + i)`. Прибавление к указателю числа `i` сдвигает адрес на `i` **элементов** (а не байтов):

```cpp
#include <iostream>

int main()
{
    int arr[] = {5, 3, 4};
    int* p = arr;                         // без &: имя массива уже адрес

    std::cout << *p << std::endl;         // Вывод: 5
    std::cout << *(p + 1) << std::endl;   // Вывод: 3
    std::cout << p[2] << std::endl;       // Вывод: 4 — индексация работает и для указателей
    std::cout << (&arr[1] == arr + 1) << std::endl;   // Вывод: 1
    return 0;
}
```

## Передача массива в функцию

Раз массив — адрес его первого элемента, функция получает **не копию**, а доступ к самим данным. Поэтому, изменив массив внутри функции, мы изменим исходный. Есть три записи параметра:

| Способ | Запись | Пример |
|---|---|---|
| с размером | `<тип> <имя>[<размер>]` | `void fun(int numbers[3])` |
| безразмерный массив | `<тип> <имя>[]` | `void fun(int numbers[])` |
| указатель | `<тип> * <имя>` | `void fun(int* numbers)` |

```cpp
#include <iostream>

void fun_sized(int numbers[3])  { std::cout << "sized:   " << numbers << std::endl; }
void fun_unsized(int numbers[]) { std::cout << "unsized: " << numbers << std::endl; }
void fun_ptr(int* numbers)      { std::cout << "pointer: " << numbers << std::endl; }

int main()
{
    int arr[] = {5, 3, 4};
    std::cout << "arr:     " << arr << std::endl;
    fun_sized(arr);
    fun_unsized(arr);
    fun_ptr(arr);          // во всех случаях печатается один и тот же адрес
    return 0;
}
```

Все три записи **полностью эквивалентны**: компилятор превращает их в `int*`. Число в скобках ничего не гарантирует — функции `fun_sized` можно передать массив из 4 или 100 элементов, и это скомпилируется. Самый распространённый вариант — третий, указатель.

> [!warning] Размер теряется
> Внутри функции `sizeof(numbers)` вернёт размер **указателя** (обычно 8 байт), а не массива. Поэтому размер нужно передавать отдельным параметром, чтобы функция не вышла за границы.

```cpp
#include <iostream>

void print_numbers(int* numbers, int size)
{
    for (int i = 0; i < size; i++)
    {
        std::cout << numbers[i] << " ";
    }
    std::cout << std::endl;
}

void double_all(int* numbers, int size)   // меняет исходный массив
{
    for (int i = 0; i < size; i++)
    {
        numbers[i] *= 2;
    }
}

int main()
{
    int arr1[] = {5, 3, 4};
    int arr2[] = {1, 2, 3, 4, 5, 6};

    print_numbers(arr1, 3);   // Вывод: 5 3 4
    print_numbers(arr2, 6);   // Вывод: 1 2 3 4 5 6

    double_all(arr1, 3);
    print_numbers(arr1, 3);   // Вывод: 10 6 8  — исходный массив изменился
    return 0;
}
```

Если функция не должна менять массив, пишите `const int* numbers` — компилятор запретит запись. Подробно о параметрах и возврате значений — в [[05 Функции и рекурсия]].

## Задачи для практики

1. **Обмен через указатели.** Напишите `void swap_values(int* a, int* b)`, меняющую значения двух переменных. Решение: `int t = *a; *a = *b; *b = t;`, вызов `swap_values(&x, &y);`.
2. **Указатель третьего порядка.** Создайте `int`, `int*`, `int**`, `int***`, изменяйте значение через `***ppp` и выводите все уровни.
3. **Сумма и максимум массива** — функции `int sum(const int* a, int n)` и `int max_value(const int* a, int n)`.
4. **Разворот массива** на месте: функция `reverse(int* a, int n)`, меняющая местами `a[i]` и `a[n-1-i]`.

## Частые ошибки

- Присваивать адрес в `int` вместо `int*`.
- Разыменовывать неинициализированный или нулевой указатель — неопределённое поведение или аварийное завершение.
- Считать, что `sizeof(arr)` в функции даёт размер массива.
- Не передавать размер вместе с массивом и выходить за границы.
- Путать `&` (адрес) и `*` (разыменование) и забывать, что `int* a, b;` создаёт только один указатель.

## Кратко (шпаргалка)

| Что | Запись | Смысл |
|---|---|---|
| Взять адрес | `&x` | адрес переменной, тип `T*` |
| Указатель на T | `T* p` | хранит адрес значения типа T |
| Разыменование | `*p` | сама ячейка: читать и писать |
| Указатель на указатель | `T** pp` | адрес переменной-указателя |
| Имя массива | `arr` | адрес первого элемента |
| Индекс | `arr[i] == *(arr + i)` | сдвиг на `i` элементов |
| Массив в функцию | `T* a, int n` | передаём адрес и размер |
