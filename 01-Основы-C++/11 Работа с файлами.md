# Работа с файлами

> [!abstract] О чём заметка
> Как программа на C++ читает данные из текстовых файлов и записывает их туда с помощью библиотеки `<fstream>`. Файлы нужны, чтобы данные пережили завершение программы.

## Что такое файл и зачем он нужен

**Файл — это именованный набор байтов, сохранённый на накопителе** (жёсткий диск, флешка, DVD). Имя имеет вид `<имя>.<расширение>`, например `data.txt`.

В рамках курса файлы делятся на два типа:
- **текстовые** — содержат текст (обычно `.txt`); работаем только с ними;
- **бинарные (двоичные)** — набор байтов, который нужно уметь правильно интерпретировать.

Переменные программы живут в оперативной памяти ([[09 Модель памяти]]): когда программа завершается, память освобождается, а при выключении компьютера всё пропадает. **Файлы лежат в постоянной памяти**, поэтому подходят для долговременного хранения.

Работа с файлом сводится к двум операциям: **читать** данные из файла в программу и **записывать** данные из программы в файл.

## Типы из `<fstream>`

Все типы лежат в пространстве имён `std` (см. [[10 Область видимости и пространства имён]]) и требуют `#include <fstream>`:

| Тип | Режим |
|---|---|
| `std::ifstream` | только чтение (input) |
| `std::ofstream` | только запись (output) |
| `std::fstream` | чтение и запись |

Создание переменной файла — это одновременно и открытие файла:

```cpp
std::ifstream fin("data.txt");
```

## Путь к файлу

- **Абсолютный путь** — полный, с диском и всеми папками: `"C:\\Users\\Admin\\Documents\\keys.txt"`.
- **Относительный путь** — отсчитывается от места запуска программы: `"data.txt"` ищется рядом с исполняемым файлом (`.exe`).

> [!warning] Обратный слеш
> В строках C++ символ `\` служебный, поэтому в путях Windows его **удваивают**: `"C:\\data.txt"`. В Linux и macOS разделитель `/`, и удваивать нечего.

> [!tip] Откуда ищется относительный путь
> Строго говоря, относительный путь считается от *текущей рабочей папки* процесса. Она часто совпадает с папкой программы, но в IDE может быть другой. Если файл «не находится», проверьте именно это.

## Чтение: `std::ifstream`

Чтение из файла устроено так же, как из консоли, только вместо `std::cin` используется переменная файла. Оператор `>>` читает **до пробела или перевода строки**, то есть по одному слову:

```cpp
#include <fstream>
#include <string>

int main()
{
    std::string s;
    std::ifstream fin("data.txt");
    fin >> s;          // первое слово файла
}
```

### Проверка, что файл открылся

Ничто не мешает указать несуществующий файл. Проверить успех можно методом **`is_open()`** (`true`/`1` — открыт, `false`/`0` — нет; есть у всех трёх типов):

```cpp
#include <iostream>
#include <fstream>

int main()
{
    std::ifstream fin_exist("data.txt");
    std::ifstream fin_not_exist("not_existing_file.txt");
    std::cout << fin_exist.is_open() << std::endl;       // 1 (если data.txt есть)
    std::cout << fin_not_exist.is_open() << std::endl;   // 0
}
```

Читать нужно только после проверки:

```cpp
std::ifstream fin("data.txt");
if (fin.is_open())
{
    // читаем из файла
}
else
{
    std::cout << "Не получилось открыть файл!" << std::endl;
}
```

### Чтение до конца файла

Заранее не знаем, сколько слов в файле: читаем, пока он не закончится. Метод **`eof()`** (end of file) возвращает `true`, когда файл закончился. Вариант из курса:

```cpp
#include <iostream>
#include <fstream>
#include <string>

int main()
{
    std::ifstream fin("data.txt");
    std::string s;
    while (!(fin >> s).eof())
    {
        std::cout << s << std::endl;   // каждое слово с новой строки
    }
}
```

> [!warning] Тонкость с последним словом
> `eof()` становится `true`, когда чтение *упёрлось* в конец файла. Если файл заканчивается словом **без** перевода строки в конце, то при чтении этого слова признак конца уже выставлен, и цикл выше его не выведет. Надёжнее писать условием само чтение:
> ```cpp
> while (fin >> s) { std::cout << s << std::endl; }
> ```
> Выражение `fin >> s` в условии равно `false`, когда прочитать не удалось.

### Чтение строки целиком

`>>` режет по пробелам. Чтобы прочитать всю строку, используйте `std::getline` (см. [[06 Строки]]):

```cpp
std::string line;
while (std::getline(fin, line))
    std::cout << "[" << line << "]\n";
// Для файла «Hello world\n42 3.5\n»:
// [Hello world]
// [42 3.5]
```

### Закрытие файла

Когда файл больше не нужен, его нужно закрыть методом **`close()`**:

```cpp
fin.close();
```

(Переменная файла закроет файл и сама при выходе из области видимости, но явный `close()` делает намерение понятным и освобождает файл сразу.)

## Запись: `std::ofstream`

Открытие на запись:

```cpp
std::ofstream fout("C:\\data.txt");
```

Два важных правила:

1. **Если файла нет, он будет создан** (пустой) по указанному пути. Для `ofstream` «несуществующий файл» не ошибка.
2. **Если файл есть, его старое содержимое удаляется** при открытии. Существует способ дописывать в конец (режим `std::ios::app`), но в этой лекции он не рассматривался.

> [!warning] Потеря данных
> Открыв важный файл через `std::ofstream` «просто посмотреть», вы его очистите.

Запись выполняется оператором `<<`, как вывод в консоль, но вместо `std::cout` — переменная файла:

```cpp
#include <fstream>

int main()
{
    std::ofstream fout("data.txt");
    fout << "Hello!" << std::endl;   // строка записана в файл
    fout.close();
}
```

## `std::fstream`

`std::fstream` открывает файл и на чтение, и на запись:

```cpp
std::fstream f("data.txt");
```

На слайдах сказано, что пока мы не умеем открывать файл с сохранением содержимого, смысла в `fstream` мало (считается, что существующий файл окажется пуст). На самом деле по умолчанию `fstream` открывается в режиме `in | out` и содержимое не стирает, но режимы открытия в курсе пока не разбирались. Поэтому на практике пока пользуются `ifstream` и `ofstream`.

## Пример: копирование слов из файла в файл

Программа читает слова из `data.txt`, записывает их в `copy.txt` по одному на строку и показывает на экране:

```cpp
#include <iostream>
#include <fstream>
#include <string>

int main()
{
    std::ifstream in("data.txt");
    if (!in.is_open())
    {
        std::cout << "Не получилось открыть data.txt\n";
        return 1;
    }
    std::ofstream out("copy.txt");

    std::string s;
    while (in >> s)
    {
        out << s << '\n';
        std::cout << s << '\n';
    }
    in.close();
    out.close();
}
// Если data.txt содержит «Hello world\n42 3.5», то на экране и в copy.txt:
// Hello
// world
// 42
// 3.5
```

## Задачи для практики
1. Прочитать числа из файла и вывести их сумму. *Решение:* `int x; int sum = 0; while (fin >> x) sum += x;`.
2. Записать в файл таблицу умножения. *Решение:* два вложенных цикла (см. [[03 Циклы]]) и `fout << i * j << ' '`.
3. Посчитать число слов и строк в файле. *Решение:* `getline` для строк, `>>` для слов.
4. Проверить, что будет, если открыть на запись существующий файл с текстом. *Решение:* содержимое пропадёт.

## Частые ошибки
- Не проверять `is_open()` и читать из ненайденного файла (программа молча «ничего не читает»).
- Одинарный `\` в пути Windows.
- Относительный путь, который ищется не в той папке, где лежит файл.
- Открыть на запись файл с нужными данными и потерять их.
- Цикл `while(!eof())` теряет или дублирует последнее слово; лучше `while (fin >> s)`.
- Забыть про `#include <fstream>` и `std::`.

## Кратко (шпаргалка)

| Задача | Код |
|---|---|
| Подключить | `#include <fstream>` |
| Читать | `std::ifstream fin("f.txt");` затем `fin >> x;` |
| Писать | `std::ofstream fout("f.txt");` затем `fout << x;` |
| Открылся ли | `fin.is_open()` |
| Конец файла | `fin.eof()` или `while (fin >> x)` |
| Закрыть | `fin.close();` |
| Строка целиком | `std::getline(fin, line)` |
