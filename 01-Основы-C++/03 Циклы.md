# Циклы

> [!abstract] О чём заметка
> Цикл позволяет выполнить один и тот же код много раз, написав его один раз. Разберём три вида циклов C++ — `while`, `do…while` и `for`, операторы `break` и `continue`, вложенные циклы.

## Зачем нужны циклы

Задача: пять раз вывести «Hello, World!». Можно пять раз скопировать строку, но для 5000 повторов это бессмысленно. **Цикл** (loop) — структура кода, которая выполняет действия несколько раз. У любого цикла есть:

- **условие** — решает, продолжать ли цикл;
- **тело цикла** — действия, выполняемые на каждом шаге;
- **шаг (итерация)** — одно выполнение тела.

```cpp
int count = 5;
while (count-- > 0) {
    std::cout << "Hello, world!" << std::endl;
}
// Выведет строку 5 раз; после цикла count == -1
```

Здесь `count--` — постфиксное уменьшение: в условии сравнивается старое значение, а затем `count` уменьшается.

## Три вида циклов

| Вид | Когда проверяется условие | Минимум выполнений тела | Когда применять |
|---|---|---|---|
| С предусловием (`while`) | до тела | 0 | число шагов заранее неизвестно, возможно, шагов не будет вовсе |
| С постусловием (`do…while`) | после тела | 1 | шагов заранее неизвестно, но хотя бы один нужен |
| С подсчётом (`for`) | до тела | 0 | число повторов известно заранее |

Аналогии из жизни:

- **предусловие** — наполнить бочку ведром из реки: сначала проверяем, полна ли бочка, и только потом идём за водой;
- **постусловие** — найти на полке книгу нужного автора: сначала берём книгу, потом смотрим, она ли это;
- **подсчёт** — положить в корзину ровно десять яблок: счётчик от 0 до 10.

## Цикл while

```text
while (условие) {
    тело цикла;
}
```

Пока условие истинно — тело выполняется; условие проверяется перед каждым шагом, поэтому тело может не выполниться ни разу.

```cpp
int a = 0;
while (a < 10) {
    std::cout << a++ << std::endl;   // 0, 1, ..., 9
}
```

Пример: вывести числа, квадрат которых меньше 100, и сам квадрат.

```cpp
int a = 1;
while (a * a < 100) {
    std::cout << a << " " << a * a << std::endl;
    a++;
}
// 1 1 / 2 4 / 3 9 / ... / 9 81
```

> [!warning] Не забывайте менять переменную условия
> Если внутри тела `a` не изменяется, условие всегда остаётся истинным и цикл **бесконечный**.

### Пример: повторный ввод

```cpp
std::string s;
std::cout << "Введите букву 'a'" << std::endl;
std::cin >> s;
while (s != "a") {
    std::cout << "Введите букву 'a'" << std::endl;
    std::cin >> s;
}
std::cout << "Спасибо!" << std::endl;
```

Обратите внимание на дублирование: запрос и чтение приходится писать дважды — до цикла и в теле. Этого неудобства лишён `do…while`.

### Пример: инвертировать число

Задача: из `123` получить `321`. Идея: брать последнюю цифру (`n % 10`) и «приписывать» её к результату справа (`rev * 10 + цифра`), а у `n` отбрасывать последнюю цифру (`n /= 10`).

| Шаг | `n` | цифра `n % 10` | `rev` |
|---|---|---|---|
| начало | 123 | — | 0 |
| 1 | 12 | 3 | 3 |
| 2 | 1 | 2 | 32 |
| 3 | 0 | 1 | 321 |

```cpp
int n = 123, rev = 0;
while (n > 0) {
    rev = rev * 10 + n % 10;
    n /= 10;
}
std::cout << rev << std::endl;   // 321
```

## Цикл do…while

```text
do {
    тело цикла;
} while (условие);     // точка с запятой обязательна!
```

Условие проверяется **после** тела, поэтому тело выполнится минимум один раз.

```cpp
int a = 0;
do {
    std::cout << a << std::endl;
    a++;
} while (a < 10);
```

Тот же повторный ввод без дублирования:

```cpp
std::string s;
do {
    std::cout << "Введите букву 'a'" << std::endl;
    std::cin >> s;
} while (s != "a");
std::cout << "Спасибо!" << std::endl;
```

Типичная задача для `do…while` — проверка корректности номера месяца:

```cpp
#include <iostream>

int main() {
    int month;
    do {
        std::cout << "Месяц (1-12): ";
        std::cin >> month;
    } while (month < 1 || month > 12);   // повторять, пока ввод некорректен
    std::cout << "Принято: " << month << std::endl;
}
// Ввод: 15, 0, 7
// Вывод: Месяц (1-12): Месяц (1-12): Месяц (1-12): Принято: 7
```

> [!note] Ввод нечисла
> Если вместо числа ввести буквы, `std::cin` перейдёт в состояние ошибки и такой цикл зациклится. Защита от этого появится позже; на этом этапе считаем, что пользователь вводит числа.

Если бы мы использовали `while`, пришлось бы сначала считать значение «до цикла».

## Цикл for

```text
for (инициализатор; условие; итератор) {
    тело цикла;
}
```

- **инициализатор** выполняется один раз перед входом в цикл;
- **условие** проверяется перед каждым шагом;
- **итератор** (изменение счётчика) выполняется после каждого шага.

```cpp
for (int a = 0; a < 5; a++) {
    std::cout << a << std::endl;   // 0 1 2 3 4
}
```

Переменная `a`, объявленная в инициализаторе, существует только внутри цикла (см. [[10 Область видимости и пространства имён]]).

Пример: степени (квадрат, куб, четвёртая) введённого пользователем числа.

```cpp
#include <iostream>

int main() {
    int x;
    std::cout << "Число: ";
    std::cin >> x;
    for (int p = 1, v = x; p <= 4; p++, v *= x) {
        std::cout << x << "^" << p << " = " << v << std::endl;
    }
}
// Ввод: 3
// Вывод:
// 3^1 = 3
// 3^2 = 9
// 3^3 = 27
// 3^4 = 81
```

В инициализаторе и итераторе можно перечислять несколько выражений через запятую. Любую из трёх частей `for` можно опустить: `for (;;)` — бесконечный цикл, как `while (true)`.

Цикл `for` по сути — сокращённая запись цикла `while` с тремя частями в одном месте:

```cpp
// эти два фрагмента делают одно и то же
for (int i = 0; i < 3; i++) { std::cout << i; }

{ int i = 0;
  while (i < 3) { std::cout << i; i++; } }
// Вывод: 012
```

> [!tip]
> `for` естественно подходит для перебора элементов массива по индексам (`for (int i = 0; i < n; i++)`), см. [[04 Массивы]].

## Оператор continue

**`continue`** немедленно переходит к следующей итерации цикла (в `for` — выполняется итератор, затем проверяется условие).

```cpp
for (int a = 0; a < 5; a++) {
    if (a % 2 == 0) {
        continue;            // чётные пропускаем
    }
    std::cout << a << std::endl;
}
// Вывод: 1 3
```

> [!warning] continue в while
> В цикле `while` перед `continue` нужно самому изменить счётчик, иначе цикл зациклится:
> ```cpp
> int a = 0;
> while (a < 10) {
>     if (a % 2 != 0) { a++; continue; }
>     std::cout << a << std::endl;   // 0 2 4 6 8
>     a++;
> }
> ```

## Оператор break

**`break`** полностью завершает ближайший цикл; управление передаётся оператору после цикла.

```cpp
for (int a = 0; a < 5; a++) {
    if (a == 4) break;
    std::cout << a << std::endl;   // 0 1 2 3
}
```

Типичное применение — **бесконечный цикл** `while (true)` с выходом по условию внутри:

```cpp
std::string cmd;
while (true) {
    std::cout << "Введите команду: ";
    std::cin >> cmd;
    if (cmd == "q" || cmd == "quit") {
        break;
    }
}
```

`break` и `continue` действуют только на самый внутренний цикл, в котором находятся.

## Вложенные циклы

Цикл в теле другого цикла называется **вложенным**. На каждом шаге внешнего цикла внутренний проходит полностью. Пример из жизни: для каждой пустой бочки (внешний цикл) носить воду до заполнения (внутренний).

Таблица умножения размера `size`:

```cpp
int size = 5;
for (int i = 1; i <= size; i++) {
    for (int j = 1; j <= size; j++) {
        std::cout << i * j << "\t";    // \t — табуляция
    }
    std::cout << std::endl;            // конец строки таблицы
}
// Вывод (через табуляцию):
// 1   2   3   4   5
// 2   4   6   8   10
// 3   6   9   12  15
// 4   8   12  16  20
// 5   10  15  20  25
```

Во внешнем цикле `i` — номер строки, во внутреннем `j` — номер столбца; ячейка таблицы — `i * j`.

Те же циклы можно записать смешанно — `for` снаружи и `while` внутри (счётчик внутреннего цикла нужно объявлять и сбрасывать внутри тела внешнего):

```cpp
int n = 6;
for (int i = 1; i < n; i++) {
    int j = 1;               // сбрасываем на каждом шаге внешнего цикла
    while (j < n) {
        std::cout << i * j << "\t";
        j++;
    }
    std::cout << std::endl;
}
```

или двумя `while`:

```cpp
int n = 6, i = 1;
while (i < n) {
    int j = 1;
    while (j < n) {
        std::cout << i * j << "\t";
        j++;
    }
    std::cout << std::endl;
    i++;
}
```

> [!note] Про границы
> В вариантах с `i < n` и `n = 6` таблица получится 5×5, а не 6×6: чтобы дойти до `n`, нужно `<=`. Следите за границами.
> Кроме того, в исходном примере из лекции внутренняя переменная `j` забыта — без объявления `int j = 1;` перед `while` код не скомпилируется; в версиях выше это исправлено.

Число шагов вложенных циклов перемножается: два цикла по $n$ шагов дают $n^2$ итераций.

## Задачи для практики

1. Добавьте в таблицу умножения заголовки строк и столбцов. *Решение:* перед вложенными циклами выведите первую строку `for (j = 1..size) cout << j << "\t"`, а в начале каждой строки — `i`:

```cpp
#include <iostream>

int main() {
    int size = 5;
    std::cout << "\t";                                  // пустой угол таблицы
    for (int j = 1; j <= size; j++) std::cout << j << "\t";
    std::cout << std::endl;
    for (int i = 1; i <= size; i++) {
        std::cout << i << "\t";                         // заголовок строки
        for (int j = 1; j <= size; j++) std::cout << i * j << "\t";
        std::cout << std::endl;
    }
}
// Вывод:
//     1   2   3   4   5
// 1   1   2   3   4   5
// 2   2   4   6   8   10
// ...
```
2. Проверка номера месяца через `do…while` (см. выше).
3. Инверсия числа через `while` (см. выше).
4. Вывод квадрата, куба и четвёртой степени введённого числа через `for`.

## Частые ошибки

- Забытое изменение переменной в `while` — бесконечный цикл.
- Лишняя `;` после `for (...)` или `while (...)`: тело становится пустым (`for (int i = 0; i < 3; i++);` ничего не делает три раза).
- Забытая `;` после `while (условие)` в `do…while`.
- Ошибка «на единицу»: `i <= n` вместо `i < n` (особенно при работе с массивами).
- `continue` в `while` без изменения счётчика.
- Использование неинициализированной переменной в условии цикла.

## Кратко (шпаргалка)

- `while (усл) {…}` — проверка до тела, 0+ раз; `do {…} while (усл);` — после, 1+ раз; `for (init; усл; шаг) {…}` — когда число шагов известно.
- `break` — выйти из цикла, `continue` — перейти к следующей итерации.
- `while (true)` + `break` — цикл с выходом из середины.
- Вложенные циклы: внутренний выполняется полностью на каждом шаге внешнего.
