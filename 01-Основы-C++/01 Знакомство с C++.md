# Знакомство с C++

> [!abstract] О чём заметка
> Что такое программа, как устроен компьютер и чем отличаются машинный код, ассемблер и языки высокого уровня. Откуда взялся C++, какие инструменты нужны, чтобы писать на нём, и как собрать и запустить первую программу «Hello, World!».

## Что такое программа

**Программа** — это набор инструкций, который выполняет компьютер для достижения определённой цели. Другими словами, это способ автоматизировать деятельность человека: то, что человек делал бы руками (считал, искал, сортировал), компьютер делает по заранее написанному алгоритму.

## Как устроен компьютер (упрощённо)

| Компонент | Что делает |
|---|---|
| **Процессор** (CPU) | Умеет исполнять команды — от этого зависят возможности компьютера. Современные процессоры многоядерны: каждое ядро исполняет команды независимо. Данные процессор берёт из **регистров** (очень быстрая память прямо на процессоре) или из ОЗУ |
| **Оперативная память** (ОЗУ, RAM) | Быстрая память для оперативных данных. Чтобы данные попали в процессор, они сначала должны оказаться в ОЗУ. При выключении питания очищается |
| **Накопители** (HDD/SSD) | Долговременная память: данные сохраняются и без питания |
| **Сеть** (сетевая карта) | Передача байтов за пределы устройства |

Запомните цепочку: программа лежит на накопителе → при запуске загружается в ОЗУ → процессор читает её команды и данные из ОЗУ. Подробнее про то, как программа использует память, см. [[09 Модель памяти]].

## От машинного кода до языков высокого уровня

**Машинный код** — это последовательность команд и их операндов в виде набора байт, который процессор умеет декодировать и выполнять: загрузить данные из ОЗУ в процессор, записать обратно, сложить, вычесть и т. д.

Писать байты вручную очень тяжело, поэтому придумали **ассемблер** (assembler): команды записываются текстовыми мнемониками, а специальная программа-ассемблер переводит их в машинный код.

```text
main.S  ──[ассемблер]──►  main
текстовый файл            исполняемый бинарный файл
```

Для сравнения — один и тот же фрагмент программы (x86-64, Linux) в машинном коде (байты в шестнадцатеричной записи) и на ассемблере:

```text
Машинный код              Ассемблер
48 c7 c0 01 00 00 00      mov $0x1, %rax      # номер системного вызова write
48 c7 c7 01 00 00 00      mov $0x1, %rdi      # куда писать (1 — экран)
48 c7 c6 00 20 40 00      mov $0x402000, %rsi # адрес выводимых данных
48 c7 c2 0d 00 00 00      mov $0xd, %rdx      # сколько байт вывести
0f 05                     syscall             # обратиться к операционной системе
```

Слева — то, что видит процессор, справа — то же самое в читаемом виде. Каждая мнемоника (`mov` — «переложить значение») соответствует одной машинной команде. Этот фрагмент выводит 13 байт на экран; на C++ тот же результат даёт одна строка `std::cout << ...`.

> [!note] Слои «от железа до программиста»
> ```text
> C++ (высокий уровень)  ──компилятор──►  машинный код  ──►  процессор
>           ▲ удобно человеку                              ▲ понятно железу
> ```
> Ассемблер — это «читаемая» запись машинного кода, а C++ — следующий уровень абстракции: не надо думать о регистрах и системных вызовах.

Но большие программы на ассемблере писать всё равно мучительно: приходится думать о регистрах и системных вызовах. Поэтому появились **языки высокого уровня** (ЯВУ). Одна строка на C++ заменяет десяток ассемблерных команд:

```cpp
int i1, i2;
bool res;
i1 = 1 + 2 + 3;
```

Перевод с ЯВУ в машинный код выполняет **компилятор** (compiler). **Компиляция** — процесс перевода исходного текста программы в машинный код, то есть создание из программы исполняемого файла.

Чтобы компилятор понимал текст однозначно, в языке есть строго определённые конструкции:

- зарезервированные (ключевые) слова: `for`, `if`, `switch`, `int` и т. д.;
- операции: `+`, `-`, `*`, `/`, `<<`, `>>` и т. д.;
- операторы вроде `sizeof`;
- модификаторы, например `unsigned`.

Все они разбираются в следующих заметках курса (например, операторы и условия — в [[02 Ветвления и логические операции]]).

## Языки C и C++

Ключевые идеи семейства C/C++:

- максимальная производительность и минимальный расход ресурсов при достаточно высоком уровне абстракции;
- возможность низкоуровневого доступа к памяти и «потенциально небезопасных» операций — разработчику предоставлена почти полная свобода (и вся ответственность).

**Название.** C — третья буква латинского алфавита (читается «си»). Постфикс `++` — отсылка к оператору инкремента: C++ — это «C с приращением».

**История:**

1. 1966 — Мартин Ричардс (Кембридж) создаёт язык BCPL.
2. 1969 — в Bell Labs на его основе появляется упрощённый язык B (Кен Томпсон при участии Денниса Ритчи).
3. 1969–1973 — Деннис Ритчи дорабатывает B и получает язык C.
4. Начало 1980-х — Бьёрн Страуструп в Bell Labs расширяет C под свои нужды; в 1983 году появляется язык C++ (сначала он назывался «C с классами»).
5. С тех пор язык сильно вырос; стандарт обновляется практически каждые несколько лет (C++11, 14, 17, 20, 23…), что говорит о его востребованности.
6. 2006 — появился язык D, потомок C++, но без обратной совместимости, поэтому большой популярности не получил.

**Где применяют C/C++:** ядра операционных систем, драйверы и микропрограммы «железа», системные библиотеки, на которых стоят другие платформы (JVM, .NET, Python, PHP), игровые движки, клиент-серверные и бизнес-приложения.

## Что нужно, чтобы писать программы

Минимум:

- **текстовый редактор** — для ввода кода;
- **компилятор** — для перевода C++ в машинный код (например, `g++`).

Для отладки и сопровождения пригодятся:

- **отладчик** (debugger) — пошаговое выполнение и поиск ошибок в логике;
- **система контроля версий** — отслеживает правки, особенно важна в командной работе (см. [[01 Знакомство с Git]]).

**Среда разработки** (IDE, Integrated Development Environment) объединяет всё это: редактор с подсказками и подсветкой синтаксиса, компилятор «по кнопке», встроенный отладчик, клиент системы контроля версий и **профайлер** (инструмент, оценивающий расход времени, памяти, сетевого и дискового трафика).

| IDE / редактор | Особенности |
|---|---|
| Microsoft Visual Studio | платная, только Windows |
| Visual Studio Code | бесплатный, Windows/macOS/Linux; формально редактор с элементами IDE |
| Qt Creator | кроссплатформенный, есть бесплатная версия, хорошая документация к библиотекам Qt |
| Xcode | полноценная IDE от Apple для macOS/iOS/watchOS/tvOS |

## Первая программа

В Visual Studio Code порядок такой: установить компилятор (g++) и расширение для C++, выбрать папку проекта, создать файл `main.cpp`, написать код, нажать **Run C/C++ File** справа вверху и при первом запуске выбрать компилятор g++. Вывод появится в консоли внизу.

```cpp
#include <iostream>            // подключаем библиотеку ввода-вывода

int main() {                   // точка входа: отсюда начинается выполнение
    std::cout << "Hello, World!" << std::endl;   // вывести строку и перейти на новую
    return 0;                  // 0 — «программа завершилась успешно»
}
// Вывод: Hello, World!
```

> [!note]
> В примере из лекции вместо `return 0;` стоит `return EXIT_SUCCESS;` — это константа из `<cstdlib>`, равная 0. Результат тот же.

Разберём по частям:

- `#include <iostream>` — подключает заголовок стандартной библиотеки с потоками ввода-вывода;
- `int main()` — функция, с которой всегда начинается выполнение программы;
- `std::cout` — стандартный поток вывода (консоль), `<<` отправляет в него данные; `std::` — пространство имён стандартной библиотеки (см. [[10 Область видимости и пространства имён]]);
- `std::endl` — перевод строки;
- `return 0;` — код возврата операционной системе.

Без IDE то же самое делается в терминале:

```bash
g++ -std=c++17 -Wall main.cpp -o main   # скомпилировать в исполняемый файл main
./main                                  # запустить
```

Ключ `-std=c++17` выбирает стандарт языка, `-Wall` включает предупреждения компилятора — привычка полезная: многие ошибки видны уже на этом этапе, а `-o main` задаёт имя результата.

Что происходит при сборке:

```text
main.cpp ──[g++: компиляция и линковка]──► main ──[запуск ./main]──► Hello, World!
 исходный                                   исполняемый
  текст                                       файл
```

Подробнее об этапах — в [[01 Компиляция и линковка]].

Небольшое расширение — ввод данных с клавиатуры через `std::cin`:

```cpp
#include <iostream>
#include <string>

int main() {
    std::string name;
    int year;
    std::cout << "Как вас зовут? ";
    std::cin >> name;                 // >> читает из потока ввода
    std::cout << "Год рождения? ";
    std::cin >> year;
    std::cout << "Привет, " << name << "! Вам примерно " << 2025 - year << " лет.\n";
    return 0;
}
// Ввод: Аня 2000
// Вывод: Привет, Аня! Вам примерно 25 лет.
```

## Частые ошибки

- Забыть `#include <iostream>` — компилятор не знает, что такое `std::cout`.
- Забыть `std::` перед `cout`/`endl`.
- Забыть точку с запятой в конце оператора.
- Забыть `()` или фигурные скобки у `main`: компилятор выдаст непонятную на первый взгляд ошибку — читайте сообщение с номером строки.
- Путать компиляцию и запуск: сначала `g++` создаёт файл, потом его запускают отдельно.

## Кратко (шпаргалка)

- Программа — набор инструкций для компьютера; процессор исполняет машинный код, данные берёт из регистров и ОЗУ.
- Ассемблер — текстовая запись машинного кода; ЯВУ (C++) переводятся в машинный код компилятором.
- C++ создан Страуструпом на основе C (1983), силён производительностью и низкоуровневым доступом.
- Минимум для работы: редактор + компилятор; удобнее — IDE (отладчик, профайлер, VCS).
- Программа начинается с `int main()`; сборка: `g++ -std=c++17 -Wall main.cpp -o main`.
