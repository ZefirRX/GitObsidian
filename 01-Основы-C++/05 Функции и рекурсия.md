# Функции и рекурсия

> [!abstract] О чём заметка
> Функция — это именованный кусок кода, который можно вызывать много раз с разными данными. Мы разберём, как объявлять и вызывать функции, как работают параметры (в том числе со значениями по умолчанию) и возвращаемое значение, зачем нужно приведение типов и что такое рекурсия — функция, вызывающая саму себя.

## Зачем нужны функции: принцип DRY

В программировании есть принцип **DRY — Don't Repeat Yourself** («не повторяйся»): любой фрагмент кода с уникальной логикой нужно выделять в переиспользуемую часть. Самый простой способ — **функция**. Если поведение придётся поменять, правка делается в одном месте, а не в десяти копиях.

Плохо (дублирование):

```cpp
#include <iostream>

int main()
{
    std::cout << "Hello, Dima" << std::endl;
    std::cout << "Hello, Vova" << std::endl;
    std::cout << "Hello, Alena" << std::endl;
    return 0;
}
```

Хорошо (логика приветствия — в одном месте):

```cpp
#include <iostream>
#include <string>

void hello(std::string name)
{
    std::cout << "Hello, " << name << std::endl;
}

int main()
{
    hello("Dima");
    hello("Vova");
    hello("Alena");
    return 0;
}
// Вывод:
// Hello, Dima
// Hello, Vova
// Hello, Alena
```

Захотите поменять «Hello» на «Привет» — правите одну строку.

## Синтаксис функции

```text
<тип возвращаемого значения> <имя функции>( [<тип параметра 1> <имя 1>, <тип параметра 2> <имя 2>, ...] )
{
    [тело функции]
}
```

- **Тип возвращаемого значения** — любой тип данных или `void`.
- **Имя функции** — любое допустимое имя C++ (обычно в `snake_case`).
- **Параметры** — любые типы, кроме `void`; список может быть пустым.
- **Тело** — действия, которые функция выполняет.

Функции в C++ могут жить отдельно от всего остального (а также внутри классов — см. [[02 Классы и объекты]]). `main` — тоже почти обычная функция; её особенность лишь в том, что выполнение программы всегда начинается с неё.

> [!note] void
> `void` — специальный «тип», обозначающий **отсутствие типа и значения**. Его используют только как тип возвращаемого значения: функция что-то делает, но ничего не отдаёт.

> [!warning] main возвращает int
> В слайдах иногда встречается `void main(...)`. Стандарт C++ требует `int main`, поэтому пишите именно так (`return 0;` в конце `main` можно опустить).

Примеры функций без параметров и с несколькими параметрами:

```cpp
#include <iostream>

// без параметров
void print_border()
{
    std::cout << "----------" << std::endl;
}

// с несколькими параметрами
void print_volume(int a, int b, int c)
{
    int volume = a * b * c;
    std::cout << volume << std::endl;
}

int main()
{
    print_border();
    print_volume(2, 3, 4);   // Вывод: 24
    print_border();
    return 0;
}
```

## Объявление и определение: порядок имеет значение

Чтобы вызвать функцию, компилятор должен уже знать её **сигнатуру** — имя, параметры и возвращаемый тип. Поэтому функция должна быть объявлена **раньше** места вызова. Такой код не скомпилируется:

```cpp
int main()
{
    hello("Dima");   // ошибка: hello ещё неизвестна
    return 0;
}

void hello(std::string name) { /* ... */ }
```

Первый способ — расставить функции в правильном порядке (`main` в самом конце). Когда функций много, это неудобно, поэтому есть второй способ: **объявление функции без тела** (прототип) — пишем только сигнатуру с `;`, а реализацию даём позже:

```cpp
#include <iostream>
#include <string>

void hello(std::string name);   // объявление (прототип)

int main()
{
    hello("Dima");              // теперь компилятор знает, что такое hello
    return 0;
}

void hello(std::string name)    // определение (реализация)
{
    std::cout << "Hello, " << name << std::endl;
}
// Вывод: Hello, Dima
```

Позже, в многофайловых проектах, прототипы выносят в заголовочные файлы (см. [[08 Многофайловые проекты и библиотеки]]).

## Параметры по умолчанию

Одному или нескольким параметрам можно задать **значение по умолчанию**. Тогда при вызове аргумент можно не указывать:

```cpp
#include <iostream>
#include <string>

void hello(std::string name = "Anonymous")
{
    std::cout << "Hello, " << name << std::endl;
}

int main()
{
    hello("Dima");   // Вывод: Hello, Dima
    hello();         // Вывод: Hello, Anonymous
    return 0;
}
```

Правила:

- параметров со значениями по умолчанию может быть сколько угодно;
- **все они должны стоять в конце списка**, после параметров без значений по умолчанию.

```cpp
int calc_sum_correct(int x = 1, int y = 2, int z = 3)   // верно
{
    return x + y + z;
}

// int calc_sum_incorrect(int x = 1, int y = 2, int z)  // ошибка компиляции:
//                                                      // z без значения идёт после параметров со значениями
```

Вызовы `calc_sum_correct()` даст 6, `calc_sum_correct(10)` — 15, `calc_sum_correct(10, 20)` — 33. Аргументы подставляются слева направо, поэтому пропустить средний, указав последний, нельзя.

## Возвращаемое значение

Чаще всего функция не печатает результат, а **возвращает** его — тогда вызывающий код сам решает, что с ним делать (вывести, сохранить, использовать в формуле). Для этого нужно:

1. указать тип возвращаемого значения (не `void`);
2. в теле написать `return <значение>;`, тип которого совпадает с объявленным.

```cpp
#include <iostream>

int calc_volume(int a, int b, int c)
{
    int volume = a * b * c;
    return volume;
}

int main()
{
    int vol = calc_volume(4, 2, 7);
    std::cout << vol << std::endl;   // Вывод: 56
    return 0;
}
```

Важные свойства `return`:

- **`return` немедленно завершает функцию.** Всё, что написано после него, не выполнится.
- **Возвращается всегда одно значение.** Вернуть сразу два числа простым `return` нельзя (позже для этого используют структуры, см. [[01 Структуры и перечисления]], или параметры-ссылки).
- В функции с типом `void` `return;` можно не писать вовсе, а можно написать **без значения** — для досрочного выхода.

```cpp
#include <iostream>

void print_positive(int a)
{
    if (a <= 0)
    {
        return;              // досрочный выход, ничего не печатаем
    }
    std::cout << a << std::endl;
}

int main()
{
    print_positive(-3);      // ничего не выведет
    print_positive(5);       // Вывод: 5
    return 0;
}
```

В функции может быть несколько `return`. Например, минимум из двух чисел:

```cpp
int get_min(int a, int b)
{
    if (a < b)
    {
        return a;
    }
    else
    {
        return b;
    }
}

// то же самое короче — через тернарный оператор (см. заметку про ветвления)
int get_min_short(int a, int b)
{
    return a < b ? a : b;
}
```

> [!warning] Не забывайте return
> Если функция объявлена с типом `int`, но какая-то ветка кода завершается без `return`, поведение неопределено. Компилятор с `-Wall` предупредит: `control reaches end of non-void function`.

## Приведение типов

### Задача: процент от числа

Нужно вычислить 17 % от 49 и оставить только целую часть: $0{,}17 \cdot 49 = 8{,}33$, ответ — 8. Наивная реализация:

```cpp
int calc_percent(int value, int percent)
{
    return percent / 100 * value;
}
// calc_percent(46, 17) вернёт 0. Почему?
```

`percent / 100` — деление двух **целых** чисел, оно целочисленное: `17 / 100 = 0`. Дальше `0 * value = 0`.

### Неявное приведение

Операции выполняются между значениями **одного типа**. Если типы разные, компилятор сам пытается их уравнять — это **неявное приведение типов (implicit conversion)**. Оно безопасно только «в больший тип»: `int -> long`, `int -> double`, `long -> double`. Приведение в обратную сторону (например, `double -> int`) теряет информацию, и на него лучше не полагаться.

Чтобы деление стало дробным, достаточно сделать дробным один из операндов:

```cpp
int calc_percent(int value, int percent)
{
    // percent / 100.0 — это double; результат double неявно превращается в int,
    // дробная часть отбрасывается (не округляется!)
    return percent / 100.0 * value;
}
```

### Явное приведение

Если вы уверены в своих действиях и готовы потерять дробную часть, приведение лучше записать **явно**. Рекомендуемый способ — оператор `static_cast<тип>(значение)`. Старая форма `(int)d` тоже работает, но её лучше не использовать: она менее заметна в коде и менее безопасна.

```cpp
#include <iostream>

int calc_percent(int value, int percent)
{
    double res = percent / 100.0 * value;
    return static_cast<int>(res);          // явно: отбрасываем дробную часть
}

int calc_percent_v2(int value, int percent)
{
    double res = static_cast<double>(percent) / 100 * value;   // приводим percent к double
    return static_cast<int>(res);
}

int main()
{
    double d = 47.6;
    int new_i = static_cast<int>(d);       // 47, потеряли 0.6
    int old_i = (int)d;                    // 47, старый стиль

    std::cout << new_i << " " << old_i << std::endl;        // Вывод: 47 47
    std::cout << calc_percent(46, 17) << std::endl;         // Вывод: 7  (0.17 * 46 = 7.82)
    std::cout << calc_percent_v2(49, 17) << std::endl;      // Вывод: 8  (0.17 * 49 = 8.33)
    return 0;
}
```

> [!tip] Усечение, а не округление
> `static_cast<int>(7.82)` даёт 7, а не 8. Для округления есть `std::round` из `<cmath>`.

## Рекурсия

Функции вызываются из других функций. Что будет, если функция вызовет **саму себя**? Этот механизм называется **рекурсией** (recursion), а вызов — рекурсивным.

Что произойдёт при запуске такой программы?

```cpp
void print_and_increase(int start)
{
    std::cout << start << std::endl;
    print_and_increase(start + 1);   // нет условия остановки!
}
```

Пару мгновений будут печататься растущие числа, а потом программа аварийно завершится с ошибкой **переполнения стека (stack overflow)**.

### Почему переполняется стек

При каждом вызове функции информация о нём (параметры, локальные переменные, адрес возврата) кладётся в специальную область памяти — **стек вызовов**, а когда функция завершается, эта запись убирается. Размер стека ограничен. При бесконечной рекурсии записей становится всё больше, пока место не кончится. Подробнее о стеке — в [[09 Модель памяти]].

Это главный минус рекурсии; второй — рекурсивный код может быть сложнее понять.

### Условие выхода

В любой рекурсивной функции нужно предусмотреть **базовый случай (условие выхода)** — ситуацию, когда функция больше не вызывает себя, а возвращает конкретный результат. Остальные ветки должны **приближать** вызов к базовому случаю.

Классический пример — факториал: $n! = n \cdot (n-1)!$, при этом $0! = 1$.

```cpp
#include <iostream>

long long factorial(int n)
{
    if (n <= 1)                    // базовый случай: 0! = 1! = 1
    {
        return 1;
    }
    return n * factorial(n - 1);   // рекурсивный случай: n уменьшается
}

int main()
{
    std::cout << factorial(5) << std::endl;   // Вывод: 120
    return 0;
}
```

Как это работает для `factorial(4)`:

```text
factorial(4) = 4 * factorial(3)
                   3 * factorial(2)
                       2 * factorial(1)
                           1            <- базовый случай, дальше идём обратно
                       2 * 1  = 2
                   3 * 2      = 6
               4 * 6          = 24
```

Каждый вызов ждёт результата следующего, поэтому в стеке одновременно «висят» 4 вызова.

### Рекурсию можно заменить циклом

Любую рекурсивную функцию можно переписать через циклы (см. [[03 Циклы]]). Версия без рекурсии не нагружает стек:

```cpp
#include <iostream>

long long factorial_loop(int n)
{
    long long result = 1;
    for (int i = 2; i <= n; i++)
    {
        result *= i;
    }
    return result;
}

int main()
{
    std::cout << factorial_loop(5) << std::endl;    // Вывод: 120
    std::cout << factorial_loop(20) << std::endl;   // Вывод: 2432902008176640000
    return 0;
}
```

> [!tip] Что выбрать
> Для простых задач вроде факториала цикл надёжнее. Рекурсия оправдана там, где задача естественно делится на подзадачи того же вида (обход деревьев, сортировки «разделяй и властвуй» — см. [[03 Сортировки]]).

## Задачи для практики

1. **Рисование прямоугольников.** Напишите функцию `draw_rect(int width, int height, char border = '*', char fill = ' ')`, которая печатает прямоугольник с заданной границей и заполнителем. Решение: две вложенных цикла по строкам и столбцам; если `i` или `j` крайние — печатаем `border`, иначе `fill`. Параметры по умолчанию стоят в конце.
2. **Факториал двумя способами** — рекурсивно и циклом (см. выше). Сравните результаты для `n = 10`.
3. **Сумма цифр числа рекурсивно.** Базовый случай: `n < 10` — вернуть `n`; иначе `n % 10 + sum_digits(n / 10)`.

## Частые ошибки

- Вызов функции до её объявления — добавьте прототип или переставьте функции.
- Параметры по умолчанию в середине списка.
- Целочисленное деление там, где ожидалась дробь (`17 / 100 == 0`).
- Рекурсия без базового случая или без приближения к нему — переполнение стека.
- Функция с непустым типом, в которой есть ветка без `return`.
- Ожидание, что `static_cast<int>` округлит число: он отбрасывает дробную часть.

## Кратко (шпаргалка)

| Понятие | Суть |
|---|---|
| DRY | один фрагмент логики — одна функция |
| Прототип | `тип имя(параметры);` — объявление без тела |
| Параметры по умолчанию | только в конце списка |
| `return` | завершает функцию, значение одно; в `void` — `return;` |
| Неявное приведение | безопасно только в больший тип (`int -> double`) |
| `static_cast<T>(x)` | рекомендуемое явное приведение |
| Рекурсия | нужен базовый случай, иначе stack overflow |
| Рекурсия vs цикл | любую рекурсию можно заменить циклом |
