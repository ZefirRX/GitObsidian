# Ветвления и логические операции

> [!abstract] О чём заметка
> Как программа принимает решения: логический тип `bool`, операторы сравнения, условные операторы `if`/`else`, `switch` и тернарный оператор `?:`. Научимся собирать сложные условия из `!`, `&&` и `||`.

## Логический тип bool

Тип **`bool`** принимает одно из двух значений: `true` (истина, при выводе — 1) или `false` (ложь, 0). Это важнейший тип: результат любого сравнения в C++ — `bool`.

```cpp
#include <iostream>

int main() {
    bool t = true, f = false;
    std::cout << t << std::endl;   // Вывод: 1
    std::cout << f << std::endl;   // Вывод: 0
    std::cout << std::boolalpha;   // дальше bool печатается словами
    std::cout << t << " " << f << std::endl;   // Вывод: true false
}
```

> [!note] bool и числа
> Внутри `bool` — это число: `true` ↔ 1, `false` ↔ 0. Любое число в условии трактуется как «ложь, если 0, иначе истина»: `if (5)` выполнится, `if (0)` — нет.

## Операторы сравнения

**Операнд** — величина, с которой работает оператор.

| Оператор | Название | Истинно, если… |
|---|---|---|
| `==` | равенство | операнды равны |
| `!=` | неравенство | операнды не равны |
| `<` | меньше | левый меньше правого |
| `>` | больше | левый больше правого |
| `<=` | меньше или равно | левый не больше правого |
| `>=` | больше или равно | левый не меньше правого |

```cpp
bool t = true, f = false, res;
res = (t == f);          // false
res = (1 == 2);          // false
res = (f == (1 == 2));   // true: false == false

int i1 = 1 + 2 + 3, i2 = 6;
res = (i1 == i2);        // true

char c1 = 'a', c2 = 'A';
res = (c1 == c2);        // false: у символов разные коды

res = (t != (1 != 2));   // false: true != true
res = (2 + 4 + 6 >= 8 + 5 + 1);   // false: 12 >= 14
```

> [!warning] `=` и `==` — не одно и то же
> `=` — присваивание, `==` — сравнение. Запись `if (x = 0)` присвоит `x` ноль и всегда будет ложной; компилятор с `-Wall` предупредит об этом.

## Условный оператор if

**`if`** выполняет блок, только если условие истинно; иначе управление просто переходит к следующему оператору.

```cpp
bool a = true;
if (a) {
    std::cout << "a is true" << std::endl;
}
```

### if–else

Если условие истинно — выполняется первый блок, иначе — второй. Оба сразу выполниться не могут.

```cpp
if (a) {
    std::cout << "a is true" << std::endl;
} else {
    std::cout << "a is false" << std::endl;
}
```

### if–else if–else

Позволяет проверить несколько **взаимоисключающих** условий. Проверка идёт сверху вниз до первого истинного условия; если истинных нет — выполняется `else`.

```cpp
int a = 0;
if (a > 0) {
    std::cout << "a is positive" << std::endl;
} else if (a < 0) {
    std::cout << "a is negative" << std::endl;
} else {
    std::cout << "a is zero" << std::endl;
}
// Вывод: a is zero
```

## Логические операторы

Они объединяют булевы значения в составные условия.

| Оператор | Название | Результат `true`, если… |
|---|---|---|
| `!` | НЕ (отрицание) | операнд `false` |
| `&&` | И | оба операнда `true` |
| `\|\|` | ИЛИ | хотя бы один операнд `true` |

Таблицы истинности:

| `a` | `b` | `a && b` | `a \|\| b` |
|---|---|---|---|
| true | true | true | true |
| true | false | false | true |
| false | true | false | true |
| false | false | false | false |

**Приоритет** (от высокого к низкому): `!`, затем `&&`, затем `||`. Порядок меняют скобками: `a || b && c` — это `a || (b && c)`.

### Ленивое вычисление (короткое замыкание)

- `&&` вычисляет правый операнд **только если левый `true`**;
- `||` вычисляет правый операнд **только если левый `false`**.

```cpp
#include <iostream>

bool check(const char* name, bool value) {
    std::cout << "проверяю " << name << std::endl;
    return value;
}

int main() {
    if (check("A", false) && check("B", true)) {}   // A ложно → B не вызывается
    if (check("C", true)  || check("D", true))  {}  // C истинно → D не вызывается
}
// Вывод:
// проверяю A
// проверяю C
```

Это используют для защитных проверок: `if (i < n && arr[i] > 0)` — к `arr[i]` обращаемся, только если индекс допустим.

## Вложенные ветвления

Внутри `if` можно писать другие `if` (глубина вложенности любая). Пример: максимум из трёх чисел.

```cpp
int a = 1, b = 2, c = 3, result;
if (a > b) {
    if (a > c) { result = a; }
    else       { result = c; }
} else {
    if (b > c) { result = b; }
    else       { result = c; }
}
std::cout << result << std::endl;   // 3
```

## Оператор switch

**`switch`** сравнивает значение выражения с набором констант и при первом совпадении переходит к соответствующему блоку `case`; если совпадений нет — выполняется `default`.

```cpp
int num = 3;
switch (num) {
    case 1: std::cout << "One" << std::endl;   break;
    case 2: std::cout << "Two" << std::endl;   break;
    case 3: std::cout << "Three" << std::endl; break;
    default: std::cout << "Other number" << std::endl; break;
}
// Вывод: Three
```

Правила:

- выражение должно быть **целочисленного типа** (`char`, `short`, `int`, `long`, `long long`) или `enum`; `double` и строки не подходят;
- значения `case` — константы, **повторяться они не могут**;
- из блока нужно выйти через `break` (или `return`), иначе выполнение «проваливается» в следующий `case`.

Несколько меток на один блок — удобный способ объединить значения:

```cpp
switch (num) {
    case 1:
    case 3: std::cout << "Odd" << std::endl;  break;
    case 2:
    case 4: std::cout << "Even" << std::endl; break;
    default: std::cout << "Parity error" << std::endl; break;
}
```

> [!warning] Провал (fall-through)
> Если забыть `break`, выполнятся и следующие блоки:
> ```cpp
> switch (1) { case 1: std::cout << "one\n"; case 2: std::cout << "two\n"; break; }
> // Вывод: one, two
> ```

> [!warning] Висячий else
> `else` всегда относится к **ближайшему** `if`, а не к тому, под которым выровнен. Чтобы не ошибиться, всегда ставьте фигурные скобки, даже вокруг одного оператора (`g++ -Wall` предупреждает об этом: `-Wdangling-else`).
> ```cpp
> int k = 5;
> if (k > 0)
>     if (k > 10) std::cout << "big\n";
>     else std::cout << "small positive\n";   // относится ко ВТОРОМУ if
> // Вывод: small positive
> ```

`switch` — более читаемая замена длинной цепочки `if (x == 1) … else if (x == 2) …`, когда сравнивается одна переменная с константами. Допустимы и вложенные `switch`. В лекции так проверяют расширение файла `jpg`/`jpeg` (в любом регистре): по первой букве, затем по второй и т. д. Иногда это быстрее цепочки сравнений строк, но читается тяжело. Рабочая версия в виде функции (подробнее о функциях — [[05 Функции и рекурсия]]; `std::string` — [[06 Строки]]):

```cpp
#include <iostream>
#include <string>

bool isJpeg(const std::string& e) {
    if (e.size() < 3) return false;
    switch (e[0]) {
    case 'j': case 'J':
        switch (e[1]) {
        case 'p': case 'P':
            switch (e[2]) {
            case 'g': case 'G': return e.size() == 3;          // jpg
            case 'e': case 'E':
                if (e.size() != 4) return false;
                switch (e[3]) { case 'g': case 'G': return true; default: return false; } // jpeg
            default: return false;
            }
        default: return false;
        }
    default: return false;
    }
}

int main() {
    std::cout << std::boolalpha;
    std::cout << isJpeg("jpg") << " " << isJpeg("JPEG") << " " << isJpeg("png") << std::endl;
    // Вывод: true true false
}
```

Злоупотреблять таким подходом не стоит.

> [!example] Что выведет программа?
> ```cpp
> int a = 6;
> if (a > -10 && a < 10) {
>     switch (a % 2) {
>         case 0:  std::cout << (a < 0 ? "negative " : "") << "even" << std::endl; break;
>         default: std::cout << (a < 0 ? "negative " : "") << "odd"  << std::endl; break;
>     }
> }
> ```
> Условие `-10 < 6 < 10` истинно, `6 % 2 == 0`, число не отрицательное, поэтому: **`even`**.

## Тернарный оператор ?:

Единственный оператор C++ с тремя операндами:

```text
условие ? выражение_если_истина : выражение_если_ложь
```

Запомнить просто: «это условие истинно? да : нет».

```cpp
int a = 0;
std::string result = a >= 0 ? "positive" : "negative";
std::cout << result << std::endl;   // positive
```

Эквивалент через `if-else`:

```cpp
std::string result;
if (a >= 0) result = "positive";
else        result = "negative";
```

Тернарный оператор **правоассоциативен**: `a ? b : c ? d : e` читается как `a ? b : (c ? d : e)`. Поэтому его можно вкладывать; если форматировать «лесенкой», читается хорошо:

```cpp
int a = 3;
std::string result = a == 1 ? "one"
                   : a == 2 ? "two"
                   : a == 3 ? "three"
                   :          "Unknown";
// result == "three"
```

Максимум из трёх чисел тернарным оператором:

```cpp
int a = 1, b = 2, c = 3;
int result = a > b ? (a > c ? a : c)
                    : (b > c ? b : c);   // 3
```

> [!tip]
> Тернарный оператор хорош для коротких выбор-значений. Если ветви содержат несколько действий или вложенность глубже двух уровней — используйте `if`.

## Задачи для практики

1. Что выведет код из блока «Что выведет программа?» выше при `a = -7`? *Решение:* условие `-10 < a < 10` истинно, `-7 % 2 == -1` (остаток от деления сохраняет знак делимого), попадаем в `default`, число отрицательное — выведется `negative odd`.
2. Определить, является ли год високосным. *Решение:* `(y % 4 == 0 && y % 100 != 0) || y % 400 == 0`.
3. Прочитать число и вывести «positive», «negative» или «zero» (`if-else if-else`), затем то же через вложенный `?:`.
4. По номеру дня недели (1–7) вывести «weekday»/«weekend» с помощью `switch` с несколькими метками.

```cpp
#include <iostream>

int main() {
    int y = 2024;
    bool leap = (y % 4 == 0 && y % 100 != 0) || y % 400 == 0;
    std::cout << std::boolalpha << leap << std::endl;   // Вывод: true
}
```

## Частые ошибки

- `=` вместо `==` в условии.
- Пропущенный `break` в `case`.
- Использование нецелочисленного типа (`double`, `std::string`) в `switch`.
- Условие вида `0 < x < 10`: оно компилируется, но не означает «x между 0 и 10»: сначала `0 < x` даёт `true`/`false` (1 или 0), а затем это число сравнивается с 10 — результат всегда `true`. Правильно: `x > 0 && x < 10`.
- Забытые фигурные скобки у вложенного `if` — «висячий» `else`.
- Побочные эффекты в правой части `&&`/`||` — она может не выполниться.

## Кратко (шпаргалка)

- `bool` — `true`/`false`; сравнения (`== != < > <= >=`) возвращают `bool`.
- Логика: `!` (самый высокий приоритет), `&&`, `||`; `&&` и `||` ленивы.
- `if / else if / else` — выбор по условию; `switch` — выбор по целочисленному значению, не забывайте `break`.
- `условие ? a : b` — выражение-выбор, правоассоциативное.
